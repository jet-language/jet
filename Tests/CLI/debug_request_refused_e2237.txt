Error [jet.DebugRequestRefused]: The debugger can't do this here: going back needs a replay: start the session with `jet debug --replay=NAME`.
 Why: The debugger shows only what the program, or the recording that runs it again, holds: going back needs a replay with an earlier point to go to, and a watch needs a local, a field path or a List item of the selected frame with bytes to watch.
 Fix: Do what the message names: start the session with `jet debug --replay=NAME`, go forward before going back, or watch a local, a field path or a List item the selected frame holds.
