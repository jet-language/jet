Error [jet.DebugConfigInvalid]: Jet debug configuration is invalid: process id 0 names no process.
 Why: The debugger attaches only to the target exactly as given, so a process id that names no running process, or a program that process does not run, leaves it nothing it may attach to.
 Fix: Correct the process id or the program, in `jet debug --attach PID` or the editor's Jet debug configuration, then start the session again.
