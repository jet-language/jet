Error: Jet.DebugConfigInvalid: Jet debug configuration is invalid: process id 0 names no process.
 Why: The debugger takes its configuration exactly as given, so a field outside the values it takes, a process id that names no running process, or a program that process does not run, leaves it nothing it may do.
 Fix: Correct the named field, the process id or the program, in `jet debug --attach PID` or the editor's Jet debug configuration, then send the request again.
More: jet-lang.dev/e/Jet.DebugConfigInvalid
