Error: Jet.AttachTargetNotObserved: Jet can't attach to process 4294967295: it isn't running, or this user can't see it
 Why: An attach reads what a running program publishes about itself: its live snapshot and flight ring under `jet run --observe`, and its live blocks under `--checked-alloc` too. A process that publishes none of it has nothing to read.
 Fix: Start the program with `jet run --observe`, then attach to the pid it runs as
