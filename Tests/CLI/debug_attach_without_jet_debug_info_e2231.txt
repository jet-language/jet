Error: Jet.DebugAttachFailed: The debugger could not attach to the process: `<work>/sleeper` has no Jet debug information; build it with `jet build -O0`.
 Why: Attaching stops a running program where it is and reads its frames from its image's own debug information, which needs the system's leave to trace the process and an image built with that information.
 Fix: Choose the process again: one of your user's that runs an image built with `jet build -O0`; where the system lets a process trace only its own children (kernel.yama.ptrace_scope 1), start the program with `jet debug <file>` instead.
More: jet-lang.dev/e/Jet.DebugAttachFailed
