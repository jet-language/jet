Error: Jet.DebugAttachFailed: Jet could not attach to the process: `<work>/sleeper` has no Jet debug information; build it with `jet build -O0`.
 Why: Attaching reads a running program from another process, which the system allows only to a process of the program's user that it lets trace the program.
 Fix: Start the program from the tool that will observe it, `jet debug <file>` or `jet perf run <file>`, or let other processes trace it: kernel.yama.ptrace_scope 0, or prctl(PR_SET_PTRACER) in the program.
