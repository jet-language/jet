Error: Jet.PerfNoInstructions: `no_samples.jettrace` keeps no instruction samples
 Why: The instruction view lists the code a native run's samples landed in, which `jet perf run` keeps in the trace as it records; a trace that keeps none of it, or none of the named function or line, has nothing to list.
 Fix: Profile the program natively with `jet perf run -O2 <file.jet>`, then view its trace with `--instructions`
More: jet-lang.dev/e/Jet.PerfNoInstructions
