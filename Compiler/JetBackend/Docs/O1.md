# Jet backend optimization levels: O1 and O2

Status: design for RUST-EXIT stream S4 (brief U3), owner directive #24 (Jet's own backend builds everything at
O0/O1/O2; LLVM only as an optional, unshipped backend). D-BACKEND-OWN1=A is in force. ExecArch2's proved-rule-table
design is not ratified and is not built here: this is a conventional, measured scalar optimizer.

## Tiers and invariants

| Level | Used by (AGENTS.md I9) | Pipeline |
|---|---|---|
| O0 | `jet run`, `jet dev`, compile-time code | lower → select (no LIR passes) |
| O1 | `jet build` | lower → O1 LIR passes → select |
| O2 | `--release` | lower → O1 + O2 LIR passes → select |

- One meaning on every level (I9): every pass is a semantics-preserving rewrite of LIR (`LIR/LIR.jet` defines the
  operators exactly). Passes never call into or re-encode the runtime; runtime calls, drops and stores stay in order.
- Optimized LIR must lint. `x64_compile_module` lints its input, so an optimizer bug refuses the build with
  `LIR lint: ...` instead of producing wrong code (wrong is worse than refused).
- No undefined-behavior latitude: integer words are 64-bit two's complement; a constant fold that would need
  wrapping is not done; Float operations are never folded or reassociated (signed zeros, NaN payloads); division
  and shift semantics follow the machine instructions the selector emits.
- `Bitcast` (64-bit reinterpretation, runtime-only) is a pure value operation: renamed, shared by CSE, hoisted by
  LICM, removed when dead, but never copy-propagated (its destination may change ABI class). `InlineAsm` is an
  effect: kept when its result is dead, a barrier for CSE loads and LICM header loads, and an escape for scalar
  replacement. Fixtures: `Tests/OptFixtures/LIROps.jet`.
- Instruction selection and register allocation improvements apply at every level (they are code generation, not
  optional passes); LIR passes are what O1/O2 add.
- Compact MIR byte constants have the same packed U8 List layout at every level.
  Literal owners clone a frozen buffer using ordinary List glue rather than
  expanding tables into per-byte LIR. Global reads borrow frozen storage or
  clone it when checked ownership requires an owner, including empty and nested
  byte Lists. Fixtures: `Tests/Fixtures/Constants.jet`, `Tests/Fixtures/Statics.jet`.
- Prepared user Rust imports call the helper's exported `<checked-symbol>_cabi`
  descriptor trampoline, not a Rust ABI function. Its x64 `repr(C)` slots are
  three words (`value`, `ptr`, `len`); Float/F32 use bits and String uses exact
  UTF-8 bytes, including interior NULs. Returned String buffers are copied into
  Jet ownership and freed through `jet_ffi_cabi_free`, even when discarded.
  Read scalar/String signatures follow the generated helper's admissibility;
  signatures without a generated descriptor are refused, never layout-guessed.
  The prepared static helper archive joins the checked MIR link closure.
  Direct C scalar lowering is unchanged. `run-lower-fixtures.mjs
  --foreign-descriptors` exercises lowering, LIR lint and object selection
  without requiring an admitted executable runtime pack.

### Self-hosting merge invariants

- Read ownership receives the current lowering module so native `Close`
  implementations participate in copy/drop decisions. The context retains
  stored/returned-value and move-root facts used by partial-owner cleanup.
- Every call write-back explicitly supplies its optional rebound MIR value;
  ordinary calls use `None`, while condition waits rebind the refreshed guard.
- Runtime result payload conversion receives the route's native-list policy,
  preserving the distinction between seed record handles and native storage.
- MIR ownership lint uses Foundation's shared consumption classifier and the
  checked route borrow mask, including carrier and phi transfers.
- Callable images retain linked function offsets and pinned Core export names;
  stop-aware adapters propagate task-control stops before storing results.
- Shared UI ABI tables specify their inline List24 and Text8 offsets directly;
  compiling the backend does not depend on runtime-only sequence constants.
- Lowering evaluates nested writes and owner-derived call arguments before
  acquiring an outer mutable emitter call; scalar optimizers end block views
  before publishing rewritten blocks.
- `MapLookup` retains its place/value/cache identities during monomorphization.
  Pattern lookup caches are scoped by their match-head block, so nested matches
  preserve the outer cache without moving a map through a borrowed builder.
- The private Core build kernel is embedded beside evaluator build services;
  its session helpers are not imports from the closed public Core catalog.
- Generic Source-resource calls infer parameters inside identical applied
  owner types. Explicit generic enum constructors retain that owner and check
  their named payloads against its substituted declaration parameters.
- Host-result replacement reconstructs owned outgoing aggregate carriers;
  recursive host-shape discovery snapshots only the fields it must retain
  across node-table mutation, and build adapters are cloned before exchange.
- Explicit `T Never!` helper and method calls expose the plain success value
  before MIR local stores; explicit fallback subjects retain the carrier for
  their own checked consumption.

- Folded Map constants use the ordinary `map.set` insertion ABI: keys are
  ordered and the last duplicate wins. Their known maximum entry count permits
  one buffer allocation. Frozen globals build once during runtime startup;
  readers borrow or clone the tree, while image finalization alone restores
  its saved capacity and releases its owned entries. Repeated callable
  initialization/finalization is safe. The marker-status and lifetime fixtures
  in `Tests/Fixtures/Constants.jet` and `Tests/Fixtures/Statics.jet` model the
  compiler's prep-folded parser-contract map.
  Untyped decimal map keys recover the checked destination's word bits,
  including U64 keys with the top bit set; they must not become exact-Int
  owners or use signed ordering.
- Native preparation visits all requested roots and queued dependencies even
  after a failure. Issues retain their originating concrete function; failed
  functions remain in the inventory as signature-preserving unreachable traps.
  Independent bodies still lower. Only the final aggregate verdict disables
  entry/callable exports, so no failed module is emitted as a runnable subset.
  `fx_mono_collect_all` checks simultaneous missing-root, preparation and body
  errors alongside a successfully lowered later root.
  Native comptime and native test callers preserve every lowering issue in
  their failure detail; native tests likewise retain every object/link error,
  rather than exposing only the first diagnostic.
- Checked map lookups cache both hits and misses without turning a read into
  ownership; cached projections preserve borrowing. Range values carry the
  checked start, end and exclusive fields, including exact Int bounds.
  Binary32 arithmetic crosses explicit bitcast boundaries between its word
  carrier and single-precision scalar instructions; it is never reinterpreted
  as binary64. Fixtures: `Tests/Fixtures/MapRangeFloat.jet`.
  Binary32 conversions round at explicit single/double precision boundaries;
  checked integer targets reject nonfinite or out-of-range values before
  truncation. Fixture: `Tests/Fixtures/FloatConvert.jet` includes poisoned
  high carrier bits and the binary32 call/spill ABI.
- Iterating a View snapshots only its window with ordinary List clone/drop
  glue. Advancing or dropping an owning-element cursor must not release
  owners in the borrowed source. Fixture: `Tests/Fixtures/IterView.jet`.
  Nominal Display/Debug recurse through checked stored fields and enum
  payloads; fixture `Tests/Fixtures/Display.jet` includes compiler-shaped
  nested values rather than relying only on scalar formatting.
- The compiler's I128/U128 carriers occupy two little-endian word halves in
  inline storage; constants, enum payloads and copies preserve all 128 bits.
  Decimal formatting covers the full domain using a bounded stack buffer.
  Checked Int construction validates signed/unsigned bounds before writing
  either half, borrowing exact-Int limbs without allocating an intermediate
  owner. Fixtures: `Tests/Fixtures/Wide.jet`.
- MIR-level optimization is already done before lowering on both paths: the Jet host's driver runs
  `optimize_mir_program` (`Compiler/JetDriver/Source/Driver/Pipeline.jet`, `optimize` phase) and the golden
  harness's MIR is dumped after the Rust half's `optimize_mir_program` (`crates/jet-codegen/src/Codegen/TIR/mir.rs`,
  `JET_DUMP_MIR`). The O1 work below is therefore all at LIR and machine level.

Entry point: `lir_optimize_module(program, level)` (`Source/Opt/Opt.jet`). Callers: `Tests/GoldenLower.jet`
(`opt-level.txt`, `JET_LOWER_OPT=<n>` in `run-goldens.mjs`), the shared runtime library-object feed
(`Image/RuntimeLibrary.jet`, always level 1), and the Jet host's native route and the bootstrap
factory's native feed (`jet_cli_native_level`: `build` → O1, `run` → O0, `--release` → O2). Runtime export IDs and signatures survive
the module pipeline unchanged; the object writer re-lints its optimized input.

Golden and lowering fixtures require an explicit `JET_RUNTIME_PACK` from the
fresh same-FINAL runtime admission receipt. They write relocatable objects first
and link `.exe` files using the Jet linker; they never choose the freestanding
image runtime or a C library when the pack is absent. `Tests/TestPack.jet` supplies
the compiled Unit adapter for scalar-word entries: after `jet_rt_main` initializes
the runtime, it calls the checked entry and preserves its exit word through
`jet_rt_process_exit`. Dirty-Bool drivers retain their foreign register/stack
transport in relocatable objects. Optional C memory-loader rails remain explicit
seed verification only, not Jet-native admission.

`Tests/check-image-retirement.mjs` is the composed retirement gate. It pins the
FINAL/composed trees and pack admission receipt, compares all three caller
families against a pre-migration caller overlay, and writes caller counts and
live import-slot-to-pack-definition addresses. Its seed MIR/driver mode is
verification, not native compiler admission. The gate checks the assembled
adapter semantically, exact overflow decimals, and I32/U32/Bool/word exits.
Integer `Convert` zero-extends the source-width low bits; Linux exit keeps the
low eight bits, as the old `Image/ELF.jet` start stub did. Kernel retirement is
separate and requires the native lead's authorization after the composed proofs.

## Pass list

IDs are the work items Main hands out. "Done" means written on `native/o1`, not yet proven.

### O1 (LIR, per function unless noted)

| ID | Pass | File | State |
|---|---|---|---|
| P1 | Simplify: move/copy propagation, constant folding (word ops, compares, Overflows), integer identities, sign-test of `Or(x, c≥0)` (the exact-Int inline test with a constant operand), branch folding, unreachable-block removal, empty-block threading, straight-line block merging, dead code and dead block parameters, dense renumbering | `Opt/Simplify.jet` | done, fixtures pass |
| P2 | Strength reduction: `Mul` by 2^k → `Shl`; signed `Div`/`Rem` by 2^k → shift sequence with the truncation fix-up; `UDiv`/`URem` by 2^k → `UShr`/`And` | `Opt/Strength.jet` | done, fixtures pass, wired (before P1) |
| P3 | Exact-Int inline facts: on the true edge of an inline test (`Compare(Ge, x ~| (x << 1), 0)`, every leaf of an `Or` tree accounted for) `x` is inline in every block that edge's target dominates (target with that single incoming edge; facts flow into its block params); later inline tests of only-inline values there become `Const 1`; constants in [-2^62, 2^62) are inline. Cooper-Harvey-Kennedy dominators, preorder walk with an undo log | `Opt/Facts.jet` | done, fixtures pass, wired (after P2, before P1) |
| P4 | Inlining (module): direct callees of ≤40 instructions, ≤200 inlined instructions per caller, never a callee in a recursive SCC (Tarjan, after P5 exposes known-pointer edges). Bottom-up (LLVM's CGSCC order): functions are visited in Tarjan's SCC completion order, callees first; each inlines the final bodies of its callees and then runs its per-function passes (`lir_optimize_module`) before any caller sees it, so wrapper chains (`rt_text_copy -> rt_text_put -> os_store_u8`) collapse completely; the size limits are measured on exactly the body cloned. Entry params alias the call args; every Return jumps to a per-site continuation block whose param is the result; StackSlots per site. Refused when an entry param's drop differs from its arg's, or when a consumed param's arg has any other use | `Opt/Inline.jet` | done, fixtures pass, wired (before P2/P1, per function in bottom-up order) |
| P5 | Direct calls for known code pointers: `Call(Value(v))` where `v` is a `FunctionAddress` with the call's signature → `Call(Function)`; then P4 can inline it | `Opt/Inline.jet` | done, fixtures pass, wired |
| P6 | Value numbering / CSE of pure instructions (Binary, Compare, PointerAdd, DataAddress, FunctionAddress, Convert; key = kind, op, renamed operands, result layout and type) scoped by the dominator tree (hashed table + undo log); Loads only within a block, invalidated by Call/Store/Drop/Move; consumed or non-Trivial results are never shared | `Opt/CSE.jet` | done, fixtures pass, wired (after P1, then P1 again) |

## Measurement

Cells: `Tools/perf/native-cells/Examples/features/<group>/<cell>.jet` with expected outputs computed independently
(JavaScript reference, `scratch/NativeO1/ref-cells.mjs`); the workloads are the function-boundary cells and gauntlet
kernels with N fixed in the source (the native harness passes no arguments). They run through `run-goldens.mjs` with
`JET_GOLDEN_FEATURES` pointing there, so a cell is only timed when its output is exact.

Per cell and checkpoint: native O0, native O1 and `jet build --release` (rustc/LLVM) wall time, median of 7 pinned runs
in one `kind=measure` proofq job; the reported number is the native/rustc ratio. Exit for O1: every baseline cell
≤2.0× rustc `--release`. A cell the native backend cannot lower yet is reported as unsupported with its first
lowering issue, never dropped.

The shared-runtime allocator cell is `Tools/perf/runtime-library/allocator.mjs`.
It links one identical C driver against the FINAL E2 O0 Jet object, the O1 Jet
object, and a Rust `std::alloc` comparison archive. Every arm performs exactly
one million 64-byte/alignment-eight allocations, writes and reads all eight
words, checks the same checksum, and frees with the original layout. Seven
CPU-pinned rounds rotate arm order; the receipt records all outputs, source and
binary hashes, medians, and O0/Rust and O1/Rust ratios. Main owns performance
admission; the cell applies no new threshold. Its Rust archive is a comparison
arm only and never becomes a Jet-native runtime input.

Runtime O1 admission also requires the complete E2 behavioral corpus on the
rebuilt pack: all 140 baseline goldens, 19 traps, allocator/global/F64/initializer
fixtures, and metadata/export audits. `Fixtures/RuntimeO1.jet` checks both the
library-feed byte oracle and preservation of OS store/load/CAS/pause/syscall
template order, plus live `FunctionAddress` and `Bitcast` operations. These
static fixtures are not a substitute for the behavioral corpus or W10.

## Proof per pass

1. LIR fixtures: `Tests/OptFixtures/*.jet` builds small LIR functions by hand, runs each pass, prints LIR before
   and after, checks literal expected LIR, and checks `lir_lint_module` is empty on both forms. Run
   `node Compiler/JetBackend/Tests/run-opt-fixtures.mjs <scratch-outdir>`; it assembles all `Source/Opt/*.jet`
   and fixture files, runs `jet run` through `cheap.sh`, and fails if any fixture fails. `JET` overrides the
   release compiler from `scratch/NativeLead4/release-52303d4e2.env`. Each fixture file contributes
   `opt_fixtures_<lowercase file stem>() -> Bool`. Strength witnesses additionally evaluate original and reduced
   64-bit forms for every shift 1..62 on signed-word samples including MIN, MAX, and negative dividends.
2. Native goldens: the 140 stems passing at O0 (`NativeLead3/nat-n7full.results.tsv`) plus the cells, at O0 and at
   O1: 0 wrong, no stem lost.
3. The cell table before/after the pass.
