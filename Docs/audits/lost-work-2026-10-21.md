## Method

1. **Conflict-resolution census** (every merge on dev whose message lists `# Conflicts:`): for each
   conflicted path, compare the merge result blob with both parents and the merge base.
   A result equal to one parent's blob means the other side's edits were discarded whole; a result
   that deletes a path the other side modified is a modify/delete conflict resolved as delete.
2. **Unmerged-ref census**: every ref whose commits are not in `dev` (`git log --all --not HEAD`), and,
   for each, the share of its added lines present anywhere in HEAD (path-insensitive).
3. **Full sweep** (`lost-work-audit.mjs`): for every merge, a 3-way line-multiset check (a clean merge
   holds `ours + theirs − base` copies of each line; deficits are lost lines, surpluses over the base are
   resurrected ones) plus declaration counts (Jet `fn`/types/`#Test`, Rust `fn`/types/`#[test]`, JS
   `function`/`test(`); for every non-merge commit > 200 lines, "closer to an older version of the path
   than to the one it replaced" and exact-blob resurrection; tests whose count fell across the whole
   commit (moves inside one commit cancel). Each finding records whether HEAD still has the lost lines
   (same path, case/separator-insensitive, and anywhere in the tree) and the dropped symbols.
