# libc census

Generated by `jet Tools/agent/LibcCensus.jet --write`; do not edit. `--check` fails when this file is stale or a row names a Jet API that does not exist.

Each row is one function family of C23 or POSIX.1-2024 (whose System Interfaces include C17's library), the Jet API that does its job, and a status:

- **covered**: the named Jet API does the family's job.
- **partial**: the named Jet API does part of it; the note says what is missing.
- **language**: the Jet language itself does the job, with no library call.
- **GAP**: Jet has no counterpart.

Standard `C23` marks an ISO C function (POSIX.1-2024 carries those C17 already had); `POSIX` marks a POSIX-only one. A name with `*` stands for an optional annex's generated set.
