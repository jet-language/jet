Prior work: `Docs/research/2026-10-29-extensibility-every-layer.md` (#6202), which counted 2,039 closed lists with only 43 generated; this report covers facts with more than one hand-written home, not closed lists in general.

Model to copy (612a9b61a2): one hand-written home (the Prelude rows), every other copy generated from it, and `--check` runs in a gate (`Tools/agent/s5/s5-gates.mjs`).

Columns: **Source** is the home that should stay hand-written. **Fix** is one of gen (generate the copy), derive (read the source at compile time) or delete (remove the copy). **Drifted** shows the values that differ today. Effort is S/M/L. **Card** is an open Tower card that already owns the finding; "none" means no open card owns it.
