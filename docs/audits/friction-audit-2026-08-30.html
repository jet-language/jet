Systemic prevention / 2 guard cards

Prevention system

Close each finding at the earliest reliable layer. Keep the common path easy, make expert control explicit, and make recurrence machine-visible.

The first version of this report treated migration as closure. That was wrong. A friction finding is closed only when the product makes the canonical form the easy form and a durable guard prevents the audited inferior form from returning.

Prevention boundary: Lints never substitute for missing APIs. Rules use AST/sema/generator IR rather than text. Statement-scoped #allow is the expert escape. Zero findings remain rewrite-later.

Never use source-text matching, identifier spelling, line counts, a global strict mode, or a lint for a missing API.

Result of prevention pass: 36 of 38 findings need a better API/default/recipe or generator; two are compiler predicate bugs; zero may remain audit-only.

Visual enforcement ladder

Use the earliest reliable layer that can make the canonical form easy or the inferior form impossible.

  1. Layer 1

    Construction or default

    Make the wrong result impossible, or make the safe common result the direct spelling.

  2. Layer 2

    Generated recipe

    jet new, package starters, docs, examples, scaffolds, and bindgen emit the canonical form.

  3. Layer 3

    Compiler diagnostic

    Reject only forms that are wrong. Registered What/Why/Fix copy and a UI snapshot are mandatory.

  4. Layer 4

    Default-on semantic lint

    Warn only after the replacement exists and the compiler can prove the exact inferior shape. Every warning has a mechanical fix or a choice between named APIs. The existing statement-scoped #allow is the expert escape.

  5. Layer 5

    Canonical-corpus ratchet

    Maintained examples, dogfood, workloads, starters, and generators are machine-checked teaching surfaces. Exceptions are per file and rule, with a required reason.

Kept as-is

Preserve the defaults that already win

The audit found strong beginner defaults with clear expert escapes. Do not trade them away while fixing nearby friction.

Keep

Typed process boundary

#CLI makes the entry type the schema. One shared parser supplies defaults and help. #Env/#Short precedence, compiled command metadata, and argv tier parity are proven.

Keep

Direct program and error flow

The implicit top-level fn run body, one print form, ?? propagation, and ?? panic("context") keep small programs honest.

Keep

File and stream rungs

fs.read and fs.write cover whole files. files.open().lines() and io.stdin().lines() expose bounded streams. APIs accept String | Path.

Keep

One collection model

Eager collections are the default. .lazy() is the visible escape. .counts(), .group_by(), and .top_n() cover common data work.

Keep

Structural data by default

Eligible records are Codable without a marker. #!Codable rejects generation. Typed and dynamic JSON remain separate, clear paths.

Keep

Explicit expert contracts

Effect inference is the default. -[]> and -[!E]> remain expert contracts. Ownership sigils, duration literals, raw message bodies, raw argv, and builders stay available when policy matters.

Keep

Concurrency as expressions

task.race, task.any, and task.all work directly. Groups remain for child ownership and scoped cleanup.

Keep

Short and full process/network rungs

process.cmd captures by default. Pipelines can run checked. http.get/post sit beside the request builder. core.math.random and core.crypto.random keep ordinary and secure randomness distinct.
