## Execution tiers — the I9 picture, measured

Default `jet run` (and `jet dev`) on canonical inputs: **2 of 15 probed entries pass**
(procpipe 533ms, parallel-grep 14.7s — 1700× its own 8.6ms AOT). Failures: timeout >180s
(binparse, csvtransform, datasummary, regex-logscan, wordfreq), E0956
(`files.rename`, for-in method collection, `parse_rfc3339`, HTTP callbacks), wrong output
(sieve `count 0` via argv loss; taskfile blank), warning-fatal exits (http-client,
http-service), silent empty stdout (web-app). The first command every beginner types is
the weakest surface Jet ships.

## Advisory rows (never gating)

**RLI5 (4 Luna max personas: beginner, Python switcher, systems expert, unattended
agent).** Common-path stumbles, all personas: un-taught core grammar (`::`, `??`, `~`,
`&`) at use sites; silent `?? 0` / empty fallbacks at trust boundaries turning bad input
into plausible output; CLI contract not derivable from source; execution-tier behavior
unpredictable from the file. Rare-path: `Float{...}` encoding tricks, packed
`key|value` records. Jet read *better* than peers on procpipe, HTTP routing, binparse
field intent, and nbody's named physics fields. Datasummary's approximate sort key is a
correctness-adjacent finding (#2263).

**Authoring cost (the agent persona's metric).** Same author, same reasoning budget:

An unattended agent pays ~8–10× more edit-check cycles to ship working Jet today. The
causes are the carded compiler/tier bugs above, not the syntax: diagnostics were
specific enough that every retry converged.

## The four questions

1. **How do we beat this on a level playing field?** Each loss names its work: L1–L5
   are compiler bugs (#2249–#2252, #2264), L6–L9 are unprofiled hot paths
   (#2253–#2256), L10–L12 are small surface additions (#2257–#2259), L13 web codegen
   (#2260), L14 SIMD (#2261, owner-directed).
2. **What must not regress while fixing?** Warm build speed, service RSS, stdlib
   depth, the LOC wins vs Rust/Go, diagnostic quality.
3. **Agent-optimality?** The closed loop is broken twice: the oracle lies (silent empty
   stdout, warning-fatal exits) and the default tier diverges from AOT so a green
   `jet run` proves nothing about `jet build` and vice versa. Fixing L2–L5 repairs the
   loop; the authoring-cost table is the metric to watch next run.
4. **What do we refuse?** Per-entry bar softening; trend history (snapshot-only by
   owner decision); crediting age/adoption to any peer.
