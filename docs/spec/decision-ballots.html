Jet — Decision Ballot

The ballot is now a live dashboard so you can submit decisions instead of copy-pasting, and undo a selection. It renders straight from docs/spec/decision-ballots.md — one source of truth, no duplicated card data.

Start it from the repo root (one command):

nix develop -c node tools/Tower/Tower.mjs serve --open

That serves the dashboard at http://127.0.0.1:4173 and opens your browser. Decide, hit Submit — your choices are written to docs/spec/ballot-results.md; then tell Claude "go" to ratify & implement. ↻ improve examples on any card queues a Claude review of that card's examples.
