# E0105: `greet` is defined twice

**Code:** `E0105`

## What

`greet` is defined twice

## Why

Every function needs a unique name so calls aren't ambiguous

## Fix

Rename or remove one of the definitions

## Example

Failing program: [`tests/ui/defined_twice.jet`](../../../tests/ui/defined_twice.jet)
