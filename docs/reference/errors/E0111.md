# E0111: `x` was made with `::`, so it can't change

**Code:** `E0111`

## What

`x` was made with `::`, so it can't change

## Why

only `:=` bindings (and `~` parameters) can be changed

## Fix

declare it with `x := ...` instead

## Example

Failing program: [`tests/ui/assign_to_val.jet`](../../tests/ui/assign_to_val.jet)
