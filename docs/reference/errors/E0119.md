# E0119: `Bogus` isn't a known effect

**Code:** `E0119`

## What

`Bogus` isn't a known effect

## Why

an effect list names compiler-known effects like `Net`, `FS`, `IO`, `DB`, or `Time`

## Fix

use one of the known effect names, or remove it from the list

## Example

Failing program: [`tests/ui/effect_unknown_name.jet`](../../../tests/ui/effect_unknown_name.jet)
