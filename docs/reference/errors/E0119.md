# E0119: there's no type called `Strng`

**Code:** `E0119`

## What

there's no type called `Strng`

## Why

the types are `Int`, `Float`, `Bool`, and `String` (plus types you define)

## Fix

check the spelling, or define the struct or enum first

## Example

Failing program: [`tests/ui/unknown_type.jet`](../../tests/ui/unknown_type.jet)
