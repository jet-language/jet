# E0108: `HookDecision.Fail` needs String (text), not Int (a whole number)

**Code:** `E0108`

## What

`HookDecision.Fail` needs String (text), not Int (a whole number)

## Why

the decision payload must match the hook's declared payload or error type

## Fix

put the value in text with interpolation: "{x}"

## Example

Failing program: [`tests/ui/decision_hook_wrong_handler.jet`](../../../tests/ui/decision_hook_wrong_handler.jet)
