# E0102: nothing named `pirnt` exists here

**Code:** `E0102`

## What

nothing named `pirnt` exists here

## Why

only functions that have been defined (or built in, like `print` / `input`) can be called

## Fix

did you mean `print`?

## Example

Failing program: [`tests/ui/unknown_function.jet`](../../tests/ui/unknown_function.jet)
