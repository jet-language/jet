# E0109: `+` can't mix Int (a whole number) and Float (a decimal number)

**Code:** `E0109`

## What

`+` can't mix Int (a whole number) and Float (a decimal number)

## Why

Jet never converts numbers silently; the two sides must match

## Fix

make both sides the same kind of number (write `2.0` instead of `2`, or drop the `.0`)
