# E0103: `print` needs exactly one thing to print

**Code:** `E0103`

## What

`print` needs exactly one thing to print

## Why

printing nothing isn't meaningful

## Fix

e.g. print("hello")

## Example

Failing program: [`tests/ui/print_needs_one.jet`](../../tests/ui/print_needs_one.jet)
