# E0101: This program has no `run` function

**Code:** `E0101`

## What

This program has no `run` function

## Why

Running a program starts at `fn run`, and the entry file doesn't define one

## Fix

Add `fn run() { ... }` to the entry file

## Example

Failing program: [`tests/ui/no_main.jet`](../../../tests/ui/no_main.jet)
