# E0101: this program has no `main` function

**Code:** `E0101`

## What

this program has no `main` function

## Why

running a program starts at `fn main`, and the entry file doesn't define one (a typed `fn run(args: T)` also works, when `T` is `@[Cli]`-derived — D-CLIFLAG1)

## Fix

add `fn main() { ... }` to the entry file

## Example

Failing program: [`tests/ui/no_main.jet`](../../tests/ui/no_main.jet)
