# E0356: `.new(...)` needs one known receiver type here

**Code:** `E0356`

## What

`.new(...)` needs one known receiver type here

## Why

the inferred constructor uses the surrounding expected type; Jet does not search a global constructor registry

## Fix

add a type annotation or write the full `Type.new(...)` form

## Example

Failing program: [`tests/ui/inferred_new_ambiguous.jet`](../../../tests/ui/inferred_new_ambiguous.jet)
