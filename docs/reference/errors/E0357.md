# E0357: identifier casing does not match its category

**Code:** `E0357`

## What

An identifier is not written in the casing required for its grammatical category.

## Why

Jet enforces one two-tier law: type-like names use PascalCase; value-like names use snake_case.

## Fix

Rename the identifier to the exact spelling shown by the diagnostic. Foreign names inside FFI binding modules are exempt.
