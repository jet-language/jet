# E0120: `name` was not moved here, so it cannot be returned as-is

**Code:** `E0120`

## What

`name` was not moved here, so it cannot be returned as-is

## Why

this function has read access only and does not own the value

## Fix

return a copy: `return name.clone();` — or take ownership with `take name: String`

## Example

Failing program: [`tests/ui/return_borrowed_param.jet`](../../tests/ui/return_borrowed_param.jet)
