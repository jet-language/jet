# E0120: `name` was not moved here, so it cannot be returned as-is

**Code:** `E0120`

## What

`name` was not moved here, so it cannot be returned as-is

## Why

this function has read access only and does not own the value

## Fix

return a copy: `return name.clone();` — or take ownership with `name: ^String`. There's no borrow-return in v1 — to share the value without a full copy, store an owned field, or reach for `Shared<T>`/`Id<T>` (coming soon) once a real program needs shared ownership
