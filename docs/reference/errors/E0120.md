# E0120: `name` was not moved here, so it cannot fill this owning destination

**Code:** `E0120`

## What

`name` was not moved here, so it cannot fill this owning destination

## Why

Read access does not transfer ownership; cloneable values copy automatically at ordinary owning destinations, but this value needs an explicit ownership decision

## Fix

Write `~name` for an owning copy, add `^` to the parameter when it should take ownership, or remove `copies: .Explicit` for the default materialization
