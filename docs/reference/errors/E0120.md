# E0120: `name` is only borrowed here, so it can't be given back as-is

**Code:** `E0120`

## What

`name` is only borrowed here, so it can't be given back as-is

## Why

this function reads the value but doesn't own it

## Fix

return a copy: `return name.clone();` — or take ownership with `take name: String`
