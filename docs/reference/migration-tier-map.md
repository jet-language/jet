# Enterprise migration tier map

Ratified by D-ADOPT-TIER1=A; every source conversion follows
D-MIGRATE-SRC1=A. The map is a product boundary, not a promise to translate
an entire foreign language.

| Source | Tier | Binding | Importing | Assisted/manual migration | Supported versions and subset | Known loss | Ownership |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Python | Source importer | py.<lib> supervised sidecar | jet import py | Import annotated scalar functions, then resolve JT0101 markers | Python 3.x; annotated int, float, str, bool, and None; straight-line locals, returns, calls, expressions, and equality assertions | Imports, dynamic values, nested control flow, exceptions, and untyped or compound signatures stay in Python | Jet migration tooling owns the importer; the adopting team owns Python, generated Jet, and the differential oracle |
| Java | Source importer | java.<lib> embedded JVM binder | jet import java | Import public static scalar methods; port the rest one method at a time | Java 8–21 syntax; long, double, boolean, String, and void; straight-line method bodies | Objects, instance state, overloads, generics, exceptions, reflection, and asynchronous APIs remain source-owned | Jet migration tooling owns conversion; the adopting team owns the JVM source, generated Jet, binder, and replacement proof |
| C# | Source importer | cs.<lib> embedded .NET binder | jet import csharp (alias: cs) | Import public static scalar methods; port managed state behind checked overlays | C# 10+ syntax; long, double, bool, string, and void; straight-line method bodies | Instance state, overloads, generics, LINQ, exceptions, reflection, and async APIs remain source-owned | Jet migration tooling owns conversion; the adopting team owns C# source, generated Jet, binder, and replacement proof |
| TypeScript | Source importer | js.<lib> target-dispatched JS binder | jet import ts (alias: typescript) | Import typed scalar functions; resolve TODOs before deleting the TS source | TypeScript 4.9+; number, boolean, string, and void; number literals are emitted as Jet Float values | Types erased at runtime, unions, generics, decorators, imports, promises, and object protocols remain source-owned | Jet migration tooling owns conversion; the adopting team owns TS source, generated Jet, JS runtime, and differential proof |
| JavaScript | Source importer | js.<lib> target-dispatched JS binder | jet import js (alias: javascript) | Import statically recognizable scalar functions; add JSDoc types when inference is ambiguous | ECMAScript 2020+; named functions and named scalar arrows with proven Int, Float, Bool, or String values | Dynamic property access, prototype behavior, closures, promises, modules, and ambiguous values become JT0101 | Jet migration tooling owns conversion; the adopting team owns JS source, generated Jet, runtime, and differential proof |
| Go | Source importer | go.<lib> C-archive binder | jet import go (alias: golang) | Import scalar functions, including main as Jet run; port the rest manually | Go 1.18+; scalar integer, float, bool, and string parameters/results; straight-line bodies | Methods, interfaces, goroutines, channels, errors, multiple returns, packages, and pointer state remain source-owned | Jet migration tooling owns conversion; the adopting team owns Go source, generated Jet, binder, and differential proof |
| Ada | Binder-only with source-preserving manual migration | ada.<lib> GNAT C-ABI binder | No source importer; `jet import ada` writes a binder stub | Keep the package in place, then port units manually behind checked bindings | Ada package specs and GNAT C-ABI exports supported by D-FFI-ADA1 | Ranges, representation clauses, exceptions, tasking, and ownership are not source-converted | The adopting team owns Ada source/toolchain and manual port; Jet owns the checked binder and stub contract |
| Pascal | Binder-only with source-preserving manual migration | pascal.<lib> FreePascal cdecl binder | No source importer; `jet import pascal` writes a binder stub | Keep the library in place, then port modules manually behind checked bindings | FreePascal exported cdecl routines and opaque class handles supported by D-FFI-PASCAL1 | Classes, runtime ownership, and unsupported bodies are not source-converted | The adopting team owns Pascal source/toolchain and manual port; Jet owns the checked binder and stub contract |
| VBA / Office automation | Binder-only with source-preserving manual migration | com.<lib> Windows COM/IDispatch type-library binder | No VBA source importer; run `jet inspect bind com` for a file-backed or registered type library | Keep the workbook or VBA project authoritative, then replace automation call sites with generated typed COM wrappers and differential checks | Windows `ITypeLib`/`ITypeInfo` automation members that pass the checked VARIANT, BSTR, dispatch, and bounded DataTree contract | VBA modules, macros, late-bound names, workbook state, and unsupported COM signatures stay source-owned | The adopting team owns the Office/VBA estate and Windows registration; Jet owns the typed binding, apartment/handle checks, and provenance |
| C | Binder-only with overlay-first replacement | c.<lib> checked C binder | No source importer | Binder call-in; replace leaf modules manually with checked overlays | Binder-supported C ABI only; no source-version conversion promise | Pointer ownership, macros, preprocessing, headers, and undefined behavior are not source-converted | The adopting team owns the C toolchain and source; Jet owns the checked binder and overlay contract |
| C++ | Binder-only with overlay-first replacement | cpp.<lib> clang-AST binder | No source importer by deliberate verdict | Binder call-in, then manual module replacement behind differential overlay proof | Binder-supported clang/C++ ABI only; no source-version conversion promise | Templates, macros, object layout, exceptions, and undefined behavior would produce unmaintainable generated Jet | The adopting team owns C++ source/toolchain and manual port; Jet owns the binder and overlay contract |

The importer rows produce ordinary editable Jet. A generated file records its
source path and D-MIGRATE-SRC1 provenance. Every omitted construct gets JT0101
with the source span, generated target, reason, and repair. The original source
is never rewritten or deleted.

Import has one source of truth: the foreign source remains authoritative until
the adopting team accepts the generated Jet. A repeat with unchanged input is
byte-stable. --update advances only an untouched generated file; simultaneous
source and owner edits produce JT0199 before the conflicted file is written.
Differential fixtures compare each supported function with its foreign oracle
and retain an explicit non-equivalence record for every omission.
