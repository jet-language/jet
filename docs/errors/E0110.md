# E0110: a condition must be Bool (true or false), but this is Int (a whole number)

**Code:** `E0110`

## What

a condition must be Bool (true or false), but this is Int (a whole number)

## Why

the program needs a clear yes or no here

## Fix

compare the value to something, e.g. `x > 0` or `name == "ok"`
