# Proposals

Idea-stage feature proposals distilled from the owner's scratchpad. Each is a
**digestible report, not a plan** — it lays out the idea, worked examples,
tradeoffs, an implementation sketch, and the open decisions the owner would
need to make. Each report ends at the decision seam: its open decisions become
Tower ballots. Once selected, the work becomes a Tower card; only exceptional
reviewed cross-epoch work also gets a sidequest plan.

Only genuinely unexplored ideas remain here. Once work is carded or ratified,
delete its proposal after durable law and implementation tracking exist.
Tower and governing specs remain authoritative.
