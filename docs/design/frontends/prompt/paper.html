Jet prompt

Quiet and typographic. Segments separated by a fading hairline that trails into the prompt chevron. Reads clean on a light terminal; a --dark variant inverts it.

height budget · 2 lines — the info line hides entirely when the shell is clean
Normal

Failing build

A failed build is the one time the info line raises its voice: a flare rule and the error code, phrased as a next action rather than an alarm.

Long-running · transient collapse

A Braille spinner and elapsed time trail the running command. When it finishes, the line collapses to a checked, timed transient (starship transient prompt) and the info line returns.
