jet env prompt · minimal

Single line, near-silent. An env marker and a chevron; the only persistent state is the chevron's exit-code color. Full status on request.

Core loop: the prompt stays out of the way until you ask it for status.

1 At rest — env name (dim) and a ready chevron. Nothing else competes for attention.
jet env · web-api
web-api ❯

The env marker is the name from env.jet — it says which dev shell you're in and nothing more. One line, one glyph.

2 Exit code = chevron color. Green after a command succeeds; red (with the code) after it fails.
jet env · web-api
web-api ❯ jet test
12 passed
web-api ❯ jet run
…server exited 1
web-api ❯ 1

The chevron carries the last exit state into the next prompt — starship's transient trick, reduced to a single character. A failing code shows its number so you never guess.

3 On demand — one keystroke expands the last build and test status inline; it collapses on the next command.
jet env · web-api
web-api ❯            ← press ^G to glance
        build ok · 0.4s     test 12/12 · 8ms ago
web-api ❯

Status is pulled, never pushed — the shell doesn't narrate background work at you. Press again to dismiss. This is the whole "expanded" surface: a single extra dim line.

4 A failing command prints the verbatim diagnostic (I4), then the next chevron goes red — no prompt clutter added.
jet env · web-api
web-api ❯ jet run
Error [E0112]: `show` wants Int (a whole number) for argument 1, but this is String (text)
  --> tests/ui/arg_type_mismatch.jet:5:10
    |
  5 |     show("hi")
    |          ^^^^
 Why: every argument must match its parameter's type
 Fix: use Int (a whole number) here
web-api ❯ 1

The prompt never editorializes the failure — the diagnostic already says what and how. The prompt only remembers the exit code.

5 NO_COLOR=1 / non-TTY — exit state moves from the chevron's color to a plain ok / x N tag.
jet env · web-api · NO_COLOR
web-api ❯ jet test
12 passed
web-api ok ❯ jet run
…server exited 1
web-api x 1 ❯ _
web-api ok ❯            (press ^G to glance)
        build ok · 0.4s     test 12/12 · 8ms ago

No color-only signal: the chevron's green/red becomes a leading ok or x N word. Wording and layout are otherwise identical.

Shared TUI palette — cyan ready · green last ok · red last failed · bright-black env/scaffolding. Yellow/magenta unused here — this prompt is deliberately quiet.
Std-only ANSI (I6): SGR color on one glyph, a single transient reveal line. NO_COLOR swaps color for an ok/x N tag.
