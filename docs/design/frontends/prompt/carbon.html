Jet prompt

The status band, shrunk to a shell prompt. One info line of whole-shell state with condition LEDs, one input line. Injected into every jet env dev shell.

height budget · 2 lines (info + input) — transient collapses history to 1
Normal

Env name, Jet version, test state, branch. Green LED = last build/tests passed. Segments are space-separated, not powerline arrows — flat and engineered.

jet env · webapp
webapp · jet 0.9.2 · ● tests ok · ⎇ main
▸
Dirty git

Working tree changes append to the branch segment: ●3 tracked edits, +42 −7 line delta. The dot turns amber the moment the tree diverges.

jet env · webapp
webapp · jet 0.9.2 · ● tests ok · ⎇ main ●3 +42 −7
▸ git add .
Failing build

A failed jet build flips the test segment to a red LED and shows the first error code inline — you see what broke without scrolling up.

jet env · webapp
webapp · jet 0.9.2 · ● build failed E0308 · ⎇ main ●1
▸
Long-running · transient collapse

While a command runs, a Braille spinner and elapsed clock live in the info line. Finished commands above collapse to a one-line transient (starship/oh-my-posh) — verb, result LED, duration — so scrollback stays skimmable.

jet env · webapp
▸ jet build            ● 1.2s
▸ jet test             ● 0.8s
webapp · ⣾ running jet bench · 12s · ⎇ main
   press Ctrl-C to stop
