jet repl · workspace

Alt-screen pane workspace. A session pane on the left, an always-visible bindings inspector on the right, docs on demand.

Core loop: evaluate on the left and watch state evolve on the right — the session and its live bindings share the screen.

1 Two panes at rest — session left, the inspector holding every binding as name : Type = value (D-REPL16=B).
jet repl · workspace (alt-screen)
jet repl · workspace ───────────────────────── ? docs   :help   :quit
┌─ session ───────────────────────────┬─ bindings ────────────────┐
│ user> nums :: [1, 2, 3, 4, 5]       │ nums  : List = [1,2,3,   │
│ [1, 2, 3, 4, 5] : List            │                  4,5]     │
│ user> total :: nums.reduce(0,     │ total : Int  = 15        │
│   (a: Int, n: Int) => (a + n))     │                            │
│ 15 : Int                          │                            │
│ user>                            │                            │
│                                     │ 2 bindings · 0 moved       │
└─────────────────────────────────────┴────────────────────────────┘
⏎ eval   ⇥ complete   ^L clear session   ^B focus bindings

The inspector is the truth of your session state — no :type round-trips. Left pane scrolls; right pane is always the current bindings.

2 Evaluate — a new binding lights up in the inspector the instant it lands (magenta row = just changed).
jet repl · workspace (alt-screen)
jet repl · workspace ───────────────────────── ? docs   :help   :quit
┌─ session ───────────────────────────┬─ bindings ────────────────┐
│ user> doubled := nums.map(         │ nums    : List = [1,2,3, │
│   (n: Int) => (n * 2))             │                    4,5]   │
│ [2, 4, 6, 8, 10] : List           │ total   : Int  = 15      │
│ user>                            │ doubled : List = [2,4,6, │
│                                     │                    8,10]  │
│                                     │ ◂ new this step            │
│                                     │ 3 bindings · 0 moved       │
└─────────────────────────────────────┴────────────────────────────┘
⏎ eval   ⇥ complete   ^L clear session   ^B focus bindings

Mutable bindings (:=) and moved values are tracked too — the count line reflects the memory model live, so you always see what you own.

3 Docs on demand — press ? and the right column splits to show the selected symbol; bindings stay visible.
jet repl · workspace (alt-screen)
jet repl · workspace ───────────────────────── ? docs open  Esc close
┌─ session ───────────────────────────┬─ bindings ────────────────┐
│ user> nums.map                    │ nums  : List            │
│                                     │ total : Int             │
│                                     ├─ docs · map ──────────────┤
│                                     │ map (self:[T],          │
│                                     │   f:(T)->U) -> [U]         │
│                                     │ Apply f to every item,     │
│                                     │ keeping order.             │
└─────────────────────────────────────┴────────────────────────────┘
⏎ eval   ⇥ complete   ? docs   ^B focus bindings

Docs share the right column rather than covering the session — you read the signature while your own bindings stay in view. Esc collapses it.

4 An error prints in the session pane; the inspector is untouched because no binding changed.
jet repl · workspace (alt-screen)
jet repl · workspace ───────────────────────── ? docs   :help   :quit
┌─ session ───────────────────────────┬─ bindings ────────────────┐
│ user> show("hi")                    │ nums    : List           │
│ Error [E0112]: `show` wants Int    │ total   : Int            │
│   (a whole number) for argument 1,  │ doubled : List           │
│   but this is String (text)         │                            │
│  Why: every argument must match    │                            │
│   its parameter's type              │                            │
│  Fix: use Int (a whole number)     │ 3 bindings · unchanged     │
│   here                              │                            │
└─────────────────────────────────────┴────────────────────────────┘
⏎ eval   ⇥ complete   ^L clear session   ^B focus bindings

Diagnostic words and code are verbatim (I4); only soft-wrap to the pane width differs. A rejected step never mutates the inspector.

5 NO_COLOR=1 / non-TTY — the two panes and the change marker survive with zero color.
jet repl · workspace · NO_COLOR
jet repl · workspace ───────────────────────── ? docs   :help   :quit
┌─ session ───────────────────────────┬─ bindings ────────────────┐
│ user> doubled := nums.map(          │ nums    : List = [1,2,3,  │
│   (n: Int) => (n * 2))              │                    4,5]   │
│ [2, 4, 6, 8, 10] : List             │ total   : Int  = 15       │
│ user> _                             │ doubled : List = [2,4,6,  │
│                                     │                    8,10]  │
│                                     │ ◂ new this step           │
│                                     │ 3 bindings · 0 moved      │
└─────────────────────────────────────┴────────────────────────────┘

The changed row keeps its ◂ new this step marker without the highlight; panes are box-drawing, not color. Same layout piped or on a TTY.

Shared TUI palette — cyan accent/prompt · green ok · yellow warn · red error · magenta changed/selection · bright-black frame.
Std-only ANSI (I6): alt-screen buffer, box-drawing panes, SGR color, a subtle change highlight. The change marker is a glyph, so NO_COLOR keeps it.
