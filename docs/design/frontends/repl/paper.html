?-mode · inline docs

Transplant from Julia: prefix any name with ? to fold its doc into the block — signature, one-line summary, an example — without leaving the line you were on.

Diagnostic

Errors are a flare-orange block, never a wall of red. Rule, caret, one plain fix line. Words and codes are snapshot-pinned (I4); only the frame is designed.

jet repl
› show("hi")

Error [E0112]: `show` wants Int (a whole number) for argument 1, but this is String (text)
  --> <repl:6>
    |
  6 |     show("hi")
    |          ^^^^
 Why: every argument must match its parameter's type
 Fix: use Int (a whole number) here
