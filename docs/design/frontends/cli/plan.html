Plan

Every mutating command first prints a complete plan — what is added, changed, removed, plus download and closure deltas — asks once, then applies with minimal output tied back to the plan lines.

Surface CLI output Model terraform plan / nh Gate one y/N per mutation Fit 80 col
01 plan
Full diff: adds, changes, removes, and the size / generation delta.
02 confirm
One prompt. Default is no; nothing has touched the system yet.
03 apply
Quiet execution; each done line points back to a plan line.

Apply is transactional: a failed line means the plan is abandoned and the system is left exactly as the plan promised it would be before y.
