jet ? help · browser

Two-pane reference app. Categories and commands on the left, full man-depth detail on the right — usage, flags, runnable examples — with breadcrumbs.

Core loop: explore the whole tool like a reference book, moving left-to-right from category to command to detail.

1 The app — left list of categories and commands, right pane the selected command's detail. Breadcrumb up top.
jet ? · reference (alt-screen)
jet ? reference              Build & run › run › usage

↑↓ move · → into · ⏎ prefill shell · / search · q quit

Fixed panels with focus and breadcrumbs (lazygit). The left tree groups the whole CLI; the right pane is a full reference page, not a blurb.

2 Scroll the detail — runnable examples sit at the bottom of every command page; Enter on one prefills the shell.

↑↓ move · ⏎ prefill: jet run --watch src/main.jet · q quit

Examples are real, copy-paste-correct commands (drawn from examples/features/). The footer shows exactly what Enter will hand the shell.

3 Reference isn't just commands — the error codes category renders each code's page verbatim (I4).
jet ? · reference (alt-screen)
jet ? reference              Reference › error codes › E0112
┌─ commands ──────────┬─ E0112 ──────────────────────────────┐
│ ▾ Reference          │ Argument type mismatch               │
    error codes      │                                      │
│    syntax           │ Error [E0112]: `show` wants Int (a    │
│                     │ whole number) for argument 1, but     │
│                     │ this is String (text)                 │
│                     │  Why: every argument must match its   │
│                     │       parameter's type               │
│                     │  Fix: use Int (a whole number) here   │
└─────────────────────┴──────────────────────────────────────┘
↑↓ move · / search codes · q quit

The same words the compiler prints, so what you read here and what you hit in the terminal are one text. Man-depth without leaving the CLI.

Category state is ▾/▸, selection is a > row marker — both are glyphs, so a piped page keeps its shape.

Shared TUI palette — cyan headings / flags / breadcrumb · magenta selected row · red inside a rendered diagnostic (verbatim) · bright-black panel frames.
Std-only ANSI (I6): alt-screen two-pane app, box-drawing frames, breadcrumb, scrollable detail. NO_COLOR keeps tree glyphs + > selection.
