jet build

Compile the current program to a binary. Safe by default; opt into an optimized release with a flag.
USAGE
jet build [--release] [--target T] [--out PATH]
OPTIONS
--releaseoptimize; strip debug info
--target <triple>cross-compile, e.g. linux-arm64
--out <path>write the binary here
EXAMPLES
❯jet build
❯jet build --releaseenter → shell
❯jet build --target linux-arm64 --out dist/app
