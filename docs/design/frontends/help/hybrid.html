jet ? help · hybrid

One curated help. A fast overlay that opens on goals, fuzzy-finds on typing, expands to man-depth in place, and shares its index with a full two-pane reference.

Core loop: summon the overlay — empty, it offers goals; typing fuzzy-finds commands, flags, examples, and error codes; Tab expands full detail in place; Enter prefills the shell; F1 opens the same index as a full reference.

palette is the foundation — jet ? drops a fuzzy finder over the shell, Enter prefills the line and never runs it.
tasks lends the empty state — before you type, the overlay lists outcomes, so a beginner starts from a goal, not a command name.
browser lends depth two ways — Tab expands one result to man-depth inline, and F1 opens the full two-pane reference over the same index, error codes included.
1 Summon with an empty query — the overlay opens on goals, phrased as verbs. No command names needed to begin.

The empty overlay is the goal list — beginners meet outcomes first. It drops over the shell (dimmed behind), never an alt-screen takeover; Esc returns you exactly where you were.

4 Enter — the overlay closes and the command lands on the shell line, cursor ready. Help hands it over; it never runs.

web-api ❯ jet run --watch src/main.jet

The payoff: help prefills the shell, you decide when to run it. The placeholder is preselected so you type the real path over it.
