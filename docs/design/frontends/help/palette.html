jet ? help · palette

Instant overlay. jet ? drops a fuzzy finder over the shell without taking the screen; find a command, press Enter, land back on the shell line with it prefilled.

Core loop: summon, type three characters, Enter, and you're back in the shell with the command ready.

1 Summon — the overlay drops below your prompt; the shell stays visible (dimmed) behind it, never cleared.
jet env · web-api
web-api ❯ jet ?
┌─ find a command ──────────────────────────────────────────┐
│ >                                          64 shown │
├───────────────────────────────────────────────────────────┤
 jet run <file>      run a file, rebuilding if it changed     
│ jet test           run the tests in this package           │
│ jet fmt            format sources in place                  │
│ jet build          compile without running                 │
│ jet repl          start an interactive session             │
├───────────────────────────────────────────────────────────┤
│ ↑↓ move · ⏎ prefill shell · ⇥ show flags · Esc close       │
└───────────────────────────────────────────────────────────┘

No alt-screen takeover — this is fzf dropped over your shell. Esc returns you exactly where you were, nothing scrolled.

2 Type three characters — fuzzy match across commands, flags, and examples; matched letters highlighted.
jet env · web-api
web-api ❯ jet ?

├───────────────────────────────────────────────────────────┤
 jet run <file>      run a file, rebuilding if it changed     
│ jet run --watch     rerun on every save                     │
│ jet run --release   run an optimized build                  │
│ jet test --run N    run only test N                         │
├───────────────────────────────────────────────────────────┤
│ example  jet run examples/features/basics/hello.jet       │
│ ↑↓ move · ⏎ prefill shell · ⇥ show flags · Esc close       │
└───────────────────────────────────────────────────────────┘

Search covers flags and runnable examples, not just command names — the preview line shows the exact example for the selected row.

3 Tab peeks the flags of the selected command inline — no page change, still one keystroke from prefilling.

Flags expand under their command as an accordion — enough to choose, not a full man page. That depth lives in the browser archetype.

4 Enter — the overlay closes and the shell line is prefilled with the command, cursor ready to edit or run.
jet env · web-api
web-api ❯ jet run

The payoff: help hands the command to the shell, it doesn't run it for you. Fill in the file, hit Enter when you mean it (navi's prefill model).

5 NO_COLOR=1 / non-TTY — selection is a > marker, matched letters wrapped in [ ].
jet ? · NO_COLOR
web-api ❯ jet ?
┌─ find a command ──────────────────────────────────────────┐
│ > run                                         5 shown │
├───────────────────────────────────────────────────────────┤
> jet [run] <file>      run a file, rebuilding if it changed
│ jet [run] --watch     rerun on every save                 │
│ jet [run] --release   run an optimized build              │
├───────────────────────────────────────────────────────────┤
│ example  jet run examples/features/basics/hello.jet       │
│ up/down move · enter prefill shell · tab flags · esc close│
└───────────────────────────────────────────────────────────┘

Fuzzy highlight becomes [run] brackets; the selected row leads with >. Box-drawing carries the overlay with no color at all.

Shared TUI palette — cyan search caret / flags / match · magenta selected row · bright-black chrome + dimmed shell behind. Green/yellow/red reserved for status, unused in help.
Std-only ANSI (I6): inline overlay box (no alt-screen), SGR color, fuzzy-match emphasis. NO_COLOR → > selection + [ ] match.
