jet build

compile the current program to a binary. safe by default; opt into release with a flag.
USAGE
jet build [--release] [--target T] [--out PATH]
OPTIONS
--releaseoptimize; strip debug info
--target <triple>cross-compile, e.g. linux-arm64
--out <path>write the binary here
