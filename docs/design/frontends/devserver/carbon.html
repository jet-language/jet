Reconnect / reload states (polling, I6)

Rebuilding… (save detected) Reloading… (new version 5) Dev server offline — retrying (poll failed)

The injected script polls /__jet_dev_version every 400ms. Each state is a small pill in the viewport corner, never a full takeover: a save shows Rebuilding…, a version bump shows Reloading… then reloads, and a failed poll shows offline — retrying until the server answers again.
