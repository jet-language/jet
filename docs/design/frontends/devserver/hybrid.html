Mirrored status, on-demand depth

A one-line terminal status and a browser corner strip mirror the same poll — same words, same state. On error the browser strip expands to a full overlay; the terminal can expand to a request log with v. The one-line parity status is always the shared truth; depth is opt-in on either side.

Surface jet dev --target=web Parity same /__jet_dev_version poll Browser depth vite overlay Terminal depth v = request log Fit 80 col
paired is the contract — terminal line and browser strip read the identical state from one poll, so they cannot drift. quiet lends the browser its full vite-class error overlay — the corner strip is that overlay collapsed. dashboard lends the terminal an opt-in request/rebuild log under the same parity header. Neither depth is on by default; the mirrored one-liner is.

Without color the dot degrades to a bracketed word ([error]); the verbose header can't pin so it prints as a plain status line above the log. With no browser attached, the overlay falls back to the same verbatim diagnostic on the terminal — nothing is lost, it moves.
