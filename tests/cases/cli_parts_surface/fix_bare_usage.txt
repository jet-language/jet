jet fix — Apply safe automatic fixes, including `fix memory`

  jet fix <file.jet|dir>
  --json                       Emit machine-readable facts or diagnostics
  --quiet                      Suppress non-error status output
  --color                      Color: auto | always | never
  --dry-run                    Preview changes without writing
  --edition                    Apply edition migration rewrites --edition=<year>
  --all                        Apply safety classes beyond formatting and behavior-preserving
  --markers                    Move every marker set above its declaration or into its body --markers <inside|above>
  --memory-ledger              Read the memory ledger at PATH
  --style                      Run the opt-in style checks, such as impl placement; fix applies their moves
