Jet command palette
jet VERSION

Build & Run
  jet run            Run a program or project
  jet build          Create a native executable
  jet check          Check code without creating a binary
  jet test           Run tests
  jet debug          Debug a program from Jet source
  jet eval           Evaluate pure Jet and print the value (`--json` for JSON)
  jet emit           Print generated build output
  jet jobs           List named project jobs or show one
  jet cc             Compile and link C with the pinned Jetpack toolchain
  jet c++            Compile and link C++ with the pinned Jetpack toolchain
  jet crash          Name the functions and lines of a release crash report

Projects & Environments
  jet fmt            Format Jet and configured project files
  jet fix            Apply safe automatic fixes, including `fix memory`
  jet new            Create a Jet project
  jet env            Open the project development shell
  jet import         Convert supported source code into editable Jet
  jet init           Create package settings in this directory
  jet lint           Run optional code-quality checks
  jet fold           Reverse a recorded Package source transition
  jet split          Extract closed Package facts into Configs or members
  jet project        Inspect project files and modules

Packages
  jet fetch          Download locked dependencies
  jet registry       Publish and manage packages
  jet audit          Inspect implicit copies, exercised memory witnesses, or dependencies
  jet update         Update dependency or toolchain pins
  jet add            Add and download a dependency
  jet gc             Show values moved into automatic memory management
  jet clean          Remove unused package-store data
  jet cache          Manage the machine-wide artifact store
  jet search         Search the local package catalog
  jet remove         Remove a dependency

Jetos
  jet os             Manage Jetos machines and images
  jet bind           Resolve and record a checked foreign binding plan
  jet image          Build a declared container image
  jet trust          Review or change trusted authority
  jet remote         Manage host-owned remote builders

Development Server
  jet dev            Watch and run a program

Reference
  jet inspect        Explore code, builds, packages, and bindings
  jet explain        Explain a diagnostic code, build fact, generic-module value, or typed cost
  jet repl           Try Jet code interactively
  jet self           Manage the Jet installation and editor tools
  jet prove          Create a proof report for code and tests
  jet perf           Collect and inspect performance traces
  jet help           Show command help
  jet budget         Check performance limits or update baselines
  jet review         Review meaning, authority, and proof changes
  jet doc            Generate reference documentation
  jet status         Show what the project has proved
  jet merge          Merge Jet programs without losing code structure
  jet version        Show the Jet version
  jet diff           Compare two Jet programs by meaning
  jet find           Find code by type, effect, or example
  jet try            Speculatively apply a plan and re-check its claims
  jet test-compare   Compare one recorded observation corpus against its relation
  jet fill           Propose checked code for typed goals

Error Codes
  jet explain <CODE> Show a diagnostic's full help, such as `jet explain E0102`

Run `jet help` for every command's usage and flags.
