E1803

What this means:
  Application authority denies a required effect; the Why line says in one sentence what the program tried to do and which deny row refused it.

Why Jet enforces it:
  Execution stops before host state changes. Every effect is allowed unless a `deny` row takes it away: the `authority` block of `package.jet` or of the file's leading `package: { … }` block, or `--deny=<RIGHTS>` on the command. `--json` carries the raw `required_effects`, `granted_effects`, `denied_effects`, and `authority` facts.

How to fix it:
  Remove the right from the `deny` row that names it, or drop the matching `--deny` from the command; otherwise change the program so it no longer reaches the denied effect.

This explanation comes from jet's diagnostics reference.
