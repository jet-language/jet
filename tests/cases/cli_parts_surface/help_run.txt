jet run — Run a program or project

  jet run [-A] [<file.jet|dir>] [--no-prepare] [-- <args>]
  --observe                    Expose bounded live runtime facts for attachment
  --log                        Set the log level filter, such as warn,shop.db=debug; above JET_LOG
  --deep-checks                Keep every deep check, or with =<scope> (repeatable) those of one package, module, type or function, such as =tree.run
  --json                       Emit machine-readable facts or diagnostics
  --quiet                      Suppress non-error status output
  --color                      Color: auto | always | never
  --sha256                     Pin the first fetch of a URL target to this sha256, as --sha256=HEX
  -p                           Pick a workspace member by name
  --verbose                    Name the effects the program uses and show advisory lints
  --no-prepare                 Refuse Jetpack project environment preparation
  -e                           Run CODE as the body of the program's run function and show its last value, as jet -e CODE [<args>]; jet run - reads the program from standard input
  --allow                      Allow comma-separated effect roots or leaves as --allow=RIGHTS
  --allow-all                  Allow every effect, as --allow with every right, so a run names none; --deny still wins
  --deny                       Deny comma-separated effect roots or leaves as --deny=RIGHTS
  -v                           Short form of --verbose
  --gate                       Allow one audited gate as --gate name=allow
  --no-color                   Disable color in console output
  --release                    Optimize for release
  --profile                    How hard to optimize: release, debug, or a named optimization bundle
  --optimize                   How hard to optimize: none, basic or full
  --bounds                     What a failed bounds check does: fatal, report or off
  --debug-info                 Whether the image carries DWARF debug info: true, false or split
  --small                      Favor a smaller binary by keeping inlining to the O1 limits: true or false
  --inline                     Which calls the optimizer inlines: auto, always_marked or off
  --backtrace                  What a fault report shows of the stack: full, brief or off
  --dead-code                  Whether the image keeps the package's unreached functions: remove or keep
  --checked-alloc              Build with the checked memory allocator, which stops at a bad free or a write after free: true or false
  --write-generated            Whether fn build's generated sources are written to .jet/generated/: off or on
  --output-dir                 The directory jet build writes its executables to ("" is .jet/build)
  --libs                       More C libraries the native link resolves foreign symbols against
  --link-args                  More native link inputs: -L<dir>, -l<name> or a .a archive path
  --os                         The operating system the image runs on: linux, macos, windows, web, wasm or freestanding
  --min-os                     The oldest OS version the image runs on ("" is none)
  --action-timeout             How long one build step may run, such as 10min
  --set                        Set one declared package setting as key=value
  --threads                    Use at most N compiler threads (1 = one thread); without it jet picks a safe number of compiler threads
  --keep-going                 Go on past the first failure through every phase, and report every failure
  --keep-going-report          Write the --keep-going failure census, one TSV row per failure, to PATH
  --keep-going-skip            Leave ITEM out of the --keep-going collector; repeat for more
  --trace                      Stream the compiler's phases and progress to stderr, or to FILE with --trace=FILE; --trace=off streams nothing
  --trace-detail               What the trace shows: phases, or each function as well with functions
  --phase-counters             Also print each trace counter on stderr
  --opt-dump                   Show FUNCTION's IR before and after the optimizer's passes; repeat for more
  --opt-disable                Skip the optimizer pass PASS; repeat for more
  --opt-verify                 Check each function with IR Lint after every optimizer pass
  --opt-ssa-stress             Move every SSA value out of SSA through a fresh slot
  --show-default               Use and report the stock default

A program reads its input through `input`; `jet help input` lists each way.
