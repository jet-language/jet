# The spec of the emission check (check.jet).
#
# The secrets of the emission check's entry (Core/Net/SSL/TLS.jet
# `ct_entry`): its test randomness, from which every key, scalar and
# plaintext comes, the RSA key, and the DRBG of the RSA signature; and the
# ECDSA nonce and blinding generators and the generator that randomizes a
# point multiplication. Each is a function parameter, which a build at O1
# and O2 keeps where it drops a function's locals.
root __core_net_ssl_tls::ct_entry r ctx rng
root __core_crypto_ecdsa::sign_core rng blind
root __core_crypto_ecp::mul_internal rng

# The functions judged: the crypto library. The entry's own harness in
# TLS.jet carries the secrets but is not judged.
check Core/Crypto/

# Decision functions: the verdict of a constant-time compare is public (a
# tag check's result); so is X25519's all-zero output check (RFC 7748
# section 6.1), whose failure rejects the peer's key.
public __core_crypto_ctime::memcmp
public core.crypto::constant_time_equal_bytes
public __core_crypto_aead::tags_equal
public core.crypto.expert::__gcm_tag_matches
public core.crypto.expert::all_zero

# Key checks, declassified once where the key is used: each reads the
# secret parts with no test of their limbs and answers valid or not, and an
# invalid key fails the operation with an error the caller sees anyway. An
# EC private scalar in range (ECP.jet `privkey_valid`), a CRT prime as an
# exponentiation's odd modulus in range (Bignum.jet `exp_mod_modulus_ok`),
# and the RSA private parts positive and the primes odd (RSA.jet
# `rsa_check_context`).
public __core_crypto_ecp::privkey_valid
public __core_crypto_bignum::exp_mod_modulus_ok
public __core_crypto_rsa::rsa_check_context

# Verdicts fixed by construction or about thrown-away values, each read in
# constant time: a rejection-sampling draw in range (a rejected draw is
# discarded), a number fitting its output (callers write values below a
# modulus of that width), gcd_modinv_odd's argument checks, a blinding
# draw's gcd being 1 (it is for every draw but a multiple of p or q), the
# RSA input below n (public: s^e mod n gives it back) and the RSA fault
# check (a mismatch is a fault and fails the operation).
public __core_crypto_bignum::draw_in_range
public __core_crypto_bignum::core_fits
public __core_crypto_bignum::modinv_args_ok
public __core_crypto_rsa::gcd_is_one
public __core_crypto_rsa::below_modulus
public __core_crypto_rsa::fault_check_passes

# The comb's R = ±T test before its last step (ECP.jet `comb_meets_t`): the
# branch outcome is fixed by construction, so it reveals nothing. Every comb
# digit is odd (ECP.jet:1442, comb_recode_core's even-digit adjustment, as
# mbedtls ecp_comb_recode_core and ecp_mul_comb_core), which keeps R off ±T
# for every scalar in [1, N) at every step but the last; the proof is on
# `comb_meets_t`, the last step runs complete, and ECDSA.jet's test holds
# the branch untaken over random scalars.
public __core_crypto_ecp::comb_meets_t

# Whether an ECDSA signature part is zero (ECDSA.jet
# `signature_part_nonzero`): r and s are the signature's output, and a zero
# one only redraws the nonce (SEC1 4.1.3 steps 3 and 6).
public __core_crypto_ecdsa::signature_part_nonzero

# Whether a point is at infinity (ECP.jet `is_zero`): every caller fails on
# it (ECDH on a shared point at infinity, ECDSA verify, EC J-PAKE), so the
# verdict is public.
public __core_crypto_ecp::is_zero

# A Base64 text byte's class (digit, space, CR, LF, `=`, invalid,
# PEM.jet `layout_class`): the layout of a PEM body, its line breaks and
# padding, carries no key bit; the digits' values stay secret.
public __core_crypto_pem::layout_class

# Exact Int and Bool struct fields are public (lengths, counters, API
