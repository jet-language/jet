# The comb's R = ±T test before its last step (ECP.jet `comb_meets_t`): the

# digit is odd (ECP.jet:1442, comb_recode_core's even-digit adjustment, as
# mbedtls ecp_comb_recode_core and ecp_mul_comb_core), which keeps R off ±T

expected core.crypto.expert::argon2_mapping maps J1, a previous block's word, onto the reference area (Argon2id's second-half data-dependent addressing, RFC 9106 section 3.4.2)
