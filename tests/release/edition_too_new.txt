Error [E2001]: This package needs a newer Jet
 Why: Editions opt a project into a specific era of Jet syntax. A newer edition can use syntax this compiler does not understand. This toolchain supports editions up to 2028, but `package.jet` asks for `2099`.
 Fix: Upgrade with `jet self upgrade`, or set `edition: "2028"` in `package.jet`.
