Error [jet.CrashReportWithoutBuild]: This crash report has no `Build <id> (names and lines: jet crash)` line.
 Why: `jet crash` names a release program's frames from the debug info its build saved under the build id the report gives; without that line it can't tell which build crashed.
 Fix: Pipe in the whole stderr of the crashed release program: `jet crash < report.txt`.
