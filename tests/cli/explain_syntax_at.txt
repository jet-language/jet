@

What this means:
  Before a name:
    Marks a name whose value is worked out while compiling, not while the program runs. The mark is part of the name, so write it at every use.
    Example:
      @LIMIT :: 1000
      print("{@LIMIT}")
    Afterwards: The value is fixed in the built program; reading it costs nothing at run time.
