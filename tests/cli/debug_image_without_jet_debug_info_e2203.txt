Error [jet.DebuggerUnavailable]: `jet debug` could not run the native debugger: `app` has no Jet debug information; build it with `jet build -O0`.
 Why: `jet debug` runs the real compiled program traced, stopping at breakpoints and showing its frames and locals from the image's own debug information; without a program it can read and run there is nothing to step through.
 Fix: Rebuild the program with `jet build -O0` and rerun `jet debug <file>`, or use `jet run <file>` to run the program without the debugger.
More: jet-lang.dev/e/E2203
