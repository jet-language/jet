E2211

What this means:
  Jet JIT has a compiler gap for this checked program.

Why Jet enforces it:
  `jet run` uses the JIT lens and does not hide a JIT compiler gap by running AOT. The detail names the function and the missing JIT or TIR coverage.

How to fix it:
  Run `jet build <file>` and the binary for now, then report E2211 with the detail below.

This explanation comes from jet's diagnostics reference.
