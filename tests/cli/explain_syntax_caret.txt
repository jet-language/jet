^

What this means:
  Before a name (move):
    Moves the value out of the name and hands it to where the mark is written. Jet already moves a name at its last use, so the mark is optional; it makes the move exact and visible.
    Example:
      names :: ["ada", "grace"]
      archive(^names)
    Afterwards: `names` can no longer be used: a later use is error E0121. To keep using it, pass a copy with `names.copy()` instead.
    Related: E0121, E0225

  Before a parameter's type:
    `name: ^T` says the function takes ownership of that argument.
    Example:
      fn archive(name: ^String) -> String { name }
      saved :: archive(^title)
    Afterwards: The caller's value moves into the function; the caller can't use it after the call.
    Related: E0209
