Error [E2112]: Memory ledger cannot be used: no memory ledger exists at `WORKSPACE/.jet/memory/ledger-v1.jsonl`.
 Why: `jet audit memory` and `jet fix memory` read one bounded, append-only ledger of exercised GC and unsafe-sentry witnesses; they reject missing or unsafe evidence instead of guessing.
 Fix: Run the relevant workload once to create the ledger, or repair the configured `.jet/memory/ledger-v1.jsonl` path, then retry.
