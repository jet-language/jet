E2001 — `payload.jet` requests an edition this toolchain can't provide (E2-M2, D-REL3)

What: This package needs a newer Jet.

Why:  Editions opt a project into a specific era of Jet syntax. A newer edition can use syntax this compiler does not understand.

Fix:  Upgrade with `jet upgrade`, or set `edition: "2026"` in `payload.jet`.
