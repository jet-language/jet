Welcome to Jet! (vVERSION)

Usage:
  jet run [-A] [<file.jet|dir>] [--no-prepare] [-- <args>] Run a program or project
  jet build [<file.jet|dir>]           Create a native executable
  jet check [<file.jet|dir>]           Check code without creating a binary
  jet inspect <command>                Explore code, builds, packages, and bindings
  jet test [<file.jet|dir>] [<filter>] [--profile=<name>] [--filter=<text>] [--shard=<i/n>] [--list] [--results=<file>] [--optimize=<levels>] [--time-limit=<duration>] [--compiler=<jet>] [--capture=<failed|all|none>] [--fresh] [--docs] [-u] Run tests
  jet explain <CODE|FACT> [file]       Explain a diagnostic code, build fact, generic-module value, or typed cost
  jet dev [<file.jet|dir>] [-- <args>] Watch and run a program
  jet self <command>                   Manage the Jet installation and editor tools
  jet repl [<file.jet>] [--project <dir>] [--allow=<RIGHTS>] [--deny=<RIGHTS>] Try Jet code interactively
  jet fmt [args]                       Format Jet and configured project files
  jet os <command>                     Manage Jetos machines and images
  jet fix <file.jet|dir>               Apply safe automatic fixes, including `fix memory`
  jet prove [args]                     Create a proof report for code and tests
  jet fetch [args]                     Download locked dependencies
  jet debug [<file.jet>]               Debug a program from Jet source
  jet registry <command>               Publish and manage packages
  jet env <command>                    Open the project development shell
  jet new <name> [--template cli|ui|web|overrides] Create a Jet project
  jet perf <command>                   Collect and inspect performance traces
  jet budget [args]                    Check performance limits or update baselines
  jet help [<command>] [--sort frequency|az|za] Show command help
  jet update [args]                    Update dependency or toolchain pins
  jet eval <file.jet|expression>       Evaluate pure Jet and print the value (`--json` for JSON)
  jet review <base.jet> <head.jet>     Review meaning, authority, and proof changes
  jet init [args]                      Create package settings in this directory
  jet audit [args]                     Inspect implicit copies, exercised memory witnesses, or dependencies
  jet image [args]                     Build a declared container image
  jet import <language> <dir> [--dry-run|--update] Convert supported source code into editable Jet
  jet jobs [<name>]                    List named project jobs or show one
  jet gc <command>                     Show values moved into automatic memory management
  jet clean [args]                     Remove unused package-store data
  jet merge [args]                     Merge Jet programs without losing code structure
  jet add [args]                       Add and download a dependency
  jet status [<file.jet|dir>]          Show what the project has proved
  jet doc [--json|--check] [<file.jet|dir>] Generate reference documentation
  jet emit [args]                      Print generated build output
  jet lint --a11y|--complexity <file.jet> Run optional code-quality checks
  jet version [args]                   Show the Jet version
  jet bind <header.h> --pkg <lib>      Resolve and record a checked foreign binding plan
  jet cc [options] <sources>           Compile and link C with the pinned Jetpack toolchain
  jet diff [args]                      Compare two Jet programs by meaning
  jet find [--effect <effect>] [--example <input -> output>] [<query>] [<file.jet|dir>] Find code by type, effect, or example
  jet trust [args]                     Review or change trusted authority
  jet c++ [options] <sources>          Compile and link C++ with the pinned Jetpack toolchain
  jet search <query>                   Search the local package catalog
  jet fold [args]                      Reverse a recorded Package source transition
  jet split [args]                     Extract closed Package facts into Configs or members
  jet cache <command>                  Manage the machine-wide artifact store
  jet project <command>                Inspect project files and modules
  jet remote [args]                    Manage host-owned remote builders
  jet try <plan.json>                  Speculatively apply a plan and re-check its claims
  jet fill <file.jet[:line]>           Propose checked code for typed goals
  jet remove [args]                    Remove a dependency
  jet test-compare <corpus.json> [--relation=<name>] [--json] Compare one recorded observation corpus against its relation
  jet crash < <report.txt>             Name the functions and lines of a release crash report

Inspect Commands:
  jet inspect types [TARGET] [--live PID]                      Show registered type and operator facts
  jet inspect rights [TARGET] [--live PID]                     Read required, granted, denied effects, and their authority source
  jet inspect claims [TARGET] [--live PID]                     Read receipt-backed claims and their current status
  jet inspect shapes [TARGET] [--live PID]                     Read semantic shapes and their checked projections
  jet inspect decisions [TARGET] [--live PID]                  Show compiler decisions and their evidence
  jet inspect structure [TARGET] [--core] [--live PID]         Show structure and lifecycle facts
  jet inspect build [TARGET] [--coverage] [--live PID]         Read build identity, inputs, and provenance
  jet inspect gates [TARGET] [--live PID]                      Read gates with required, granted, denied effects, and authority
  jet inspect graph <file.jet>                                 Show the build graph
  jet inspect query build <file.jet>                           Search code and build information
  jet inspect explain-build <target|action|file> <file.jet>    Explain why a target, action, or file is rebuilt
  jet inspect compiler <lex|parse|check|source-map> <file>     Read compiler facts as versioned JSON
  jet inspect impact <file.jet> <symbol>                       Show code affected by a symbol
  jet inspect provenance [--json] [<dependency>]               Read dependency provenance with required, granted, denied effects, and authority
  jet inspect digest [--json] [--list-topics] [--topic <name>] Write the one-file LLM surface digest
  jet inspect env [--json] [<env.jet|config.jet>]              List typed environment reads in a config surface
  jet inspect semindex <file.jet>                              Search code facts plus required, granted, denied effects, and authority
  jet inspect output <file.jet> [<address>]                    Inspect one Output with required, granted, denied effects, and authority
  jet inspect expand [--facts <inline|memory|web|effects|layout|derive|templates|callable-signature>] [--json] <file.jet> Show expanded meaning with required, granted, denied effects, and authority
  jet inspect schema status                                    Inspect saved data schema versions
  jet inspect schema squash --before <version>                 Inspect saved data schema versions
  jet inspect codemod <plan.json> --dry-run                    Preview or apply code changes
  jet inspect codemod apply <plan.json> [--yes]                Preview or apply code changes
  jet inspect codemod undo <log.json>                          Preview or apply code changes
  jet inspect audit copies [--json] [<entry.jet>]              Inspect implicit copies, exercised memory witnesses, or dependencies
  jet inspect audit memory [--json]                            Inspect implicit copies, exercised memory witnesses, or dependencies
  jet inspect audit [--advisory-db <path>]                     Inspect implicit copies, exercised memory witnesses, or dependencies
  jet inspect bind <header.h> --pkg <lib>                      Generate Jet bindings from a foreign header
  jet inspect logs <pkg>                                       Show recent package build logs
  jet inspect info <source>.<package>                          Show package details
  jet inspect outdated                                         List dependencies with available updates
  jet inspect reserved [--json]                                List reserved words and sigils

  jet registry keygen [--registry <name>] [--force]             Create a package-signing key
  jet registry key backup [<dest>] [--registry <name>]          Manage the package-signing key

Env Commands:

  jet env hook <bash|zsh|fish>                             Print the shell auto-activation hook

Perf Commands:
  jet perf run                                              Run a program and write a .jettrace
  jet perf test                                             Run tests and write a .jettrace
  jet perf attach                                           Attach to a running process and write a .jettrace
  jet perf view                                             Show a .jettrace summary
  jet perf compare                                          Compare two .jettrace artifacts
  jet perf export                                           Export a loss-declared projection of a .jettrace

Gc Commands:
  jet gc report                                           Show values moved into automatic memory management

Cache Commands:
  jet cache status                                           Show machine-wide artifact store usage
  jet cache prune --to <size>                                Prune the artifact store to a target size
  jet cache limit --host <size>                              Set the host-wide artifact store limit

Project Commands:
  jet project parts                                            List loaded and skipped project modules

Flags:
  --live                       With inspect: Process id for a live plane scope
  --structural                 With diff/merge: Compare checked definitions by semantic identity
  --base-receipt               With review: Proof receipt for the base change-set side
  --receipt                    With review: Proof receipt for the reviewed change-set side
  --out                        With structural merge: Write the checked result to this path
  --repo                       With merge install-driver: Git worktree to configure
  --json                       Emit machine-readable facts or diagnostics
  --topic                      With inspect digest: Emit one digest topic
  --to                         With cache: Foreign registry, prune target size, or migration target version
  --list-topics                With inspect digest: List digest topics
  --kind                       With inspect gates: Filter one gate or bundle kind
  --quiet                      Suppress non-error status output
  --color                      Color: auto | always | never
  --version                    With new: Set bundle or migration version; global flag prints compiler version
  --apply                      With new: Apply the verified artifact or planned source writes
  --preview                    With new: Preview source writes, a binding plan, or an imported build graph without applying them
  --remove                     With new: Remove only unchanged outputs recorded by the scaffold receipt
  --path                       With new: Route or output path, defaulting to `/<name>`
  --route                      With new: Alias for `--path`
  --model                      With new: Model name recorded beside the route source
  --check                      With fmt/doc/split/fold: Check or preview without changing files (CI gate)
  --lang                       With fmt: Delegate non-Jet files to the environment formatter for this language
  --diff                       With fmt --check: Also print unified diffs for each changed file
  --simplify                   With fmt: Rewrite to the simplest canonical spelling
  --changed                    With fmt: Format only VCS-changed .jet files (requires git)
  --explicit-copies            With fmt: Materialize implicit read-view copies as `.copy()`
  --skipped                    With project parts: Show modules omitted from automatic discovery
  --stdin-path                 With fmt -: Path label used in diagnostics when reading from stdin
  --output                     With jobs: Select a named output, which Canvas uses as the initial selection
  --locked                     With build/fetch/jobs/inspect gates: Require locked dependency and provenance facts
  --effect                     With find: Require an effect such as FS.Read
  --example                    With find: Search by input/output example
  --lock                       With fetch/new: Lock dependency fetching or choose a migration/scaffold lock policy
  --host                       With cache limit: Host-wide store cap
  -p                           With run/dev/debug/check/build/jobs: Pick a workspace member by name
  --annotated                  With new: Include commented example deps
  --force                      With publish/inspect gates: Bypass pre-publish gate (with warning)
  --no-sign                    With publish: Skip the optional author signature (registry metadata is still signed)
  --registry                   With keygen/key: Registry name to generate or manage a signing key for
  --pkg                        With bind: Library name for the generated binding module
  --before                     With schema squash: Re-baseline migrations before this version
  --advisory-db                With audit: Path to advisory database file
  --vendor-dir                 With vendor: Directory to copy dependencies into (default vendor/)
  --sbom                       With build: Also write an SPDX SBOM next to the binary
  --verbose                    With build/jobs: Print the bridge steps; with check: print the status line, proof rows, and receipt notices; with run/dev/test: show advisory lints; with explain: show a syntax token's registry name and decision
  --template                   With new: Start from a named template: cli, ui, web, or overrides
  --sort                       With help: Order commands by use (frequency, the default), A to Z (az), or Z to A (za)
  --online                     With doctor/inspect gates: Allow network checks
  --fix                        With doctor: Apply auto-fixable problems
  --dry-run                    With fix/fmt/rewrite commands: Preview changes without writing
  --keep                       With try: Keep a clean speculative edit
  --edition                    With fix: Apply edition migration rewrites --edition=<year>
  --all                        With fix: Apply safety classes beyond formatting and behavior-preserving; with help: Also list every form this `jet` has not built yet, with the Tower card that owns its port
  --markers                    With fix: Move every marker set above its declaration or into its body --markers <inside|above>
  --try-anyway                 With inspect gates: Evaluate past unsupported features (no guarantees)
  --watch                      With dev: Re-run on dependency changes (--watch=off runs once)
  --project                    With repl: Load package settings and imports from this directory
  --no-prepare                 With run: Refuse Jetpack project environment preparation
  --pure                       With eval: Reject code with side effects
  --allow                      With run/build/jobs/repl/inspect gates: Allow comma-separated effect roots or leaves as --allow=RIGHTS
  --allow-all                  With run/build/inspect gates: Allow every effect, as --allow with every right; --deny still wins. A file starting with a #!/ line runs this way
  -A                           Short form of --allow-all
  --deny                       With run/build/jobs/repl/inspect gates: Deny comma-separated effect roots or leaves as --deny=RIGHTS
  --offline                    With env/build/test/cc/c++/inspect gates: Reuse only cached signed toolchain and package data
  --fixtures                   With env/test/cc/c++: Use an explicit fixture bundle
  --project-root               With cc/c++: Scope source paths to a project directory
  --build-root                 With cc/c++: Scope output paths to a build directory
  -c                           With cc/c++: Compile sources without linking
  -o                           With cc/c++: Choose the output path
  -MMD                         With cc/c++: Emit user-header dependency data
  -MD                          With cc/c++: Emit dependency data
  -MF                          With cc/c++: Choose the dependency-file path
  -MT                          With cc/c++: Choose the dependency target
  --sysroot                    With cc/c++: Reserved; target selects the pinned sysroot
  -I                           With cc/c++: Add a project-relative include path
  -D                           With cc/c++: Define a preprocessor symbol
  -L                           With cc/c++: Add a project-relative library path
  -l                           With cc/c++: Link a declared library
  -std                         With cc/c++: Select the language standard
  -dumpmachine                 With cc/c++: Print the pinned target triple
  -print-sysroot               With cc/c++: Print the pinned virtual sysroot
  -dumpversion                 With cc/c++: Print the pinned compiler version
  -v                           With cc/c++: Print pinned toolchain details or compile verbosely
  --gate                       With build/run/dev/jobs/check/inspect gates: Allow one audited gate as --gate name=allow
  --target                     With build/jobs/check/doctor/inspect/cc/c++: Select a target (triple, board.<name>, or named database target)
  --up                         With new: Checked forward SQL
  --sql                        With new: Alias for checked forward SQL
  --down                       With new: Checked inverse SQL for rollback
  --risk                       With new: Data-risk note shown before writes
  --no-color                   With run/test/help: Disable color in console output
  --env                        With env/test: Select one declared env.<name> module
  --preset                     With env/test: Select one declared environment preset
  --explain-partition          With build --target=web: Show which code becomes JavaScript or WebAssembly
  --fresh                      With test: Bypass only cached test results (default off); the build cache remains reusable; --fresh, `fresh: true`, `t.fresh()`
  --docs                       With test: Run checked documentation examples only (default off); --docs, `docs: true`, `t.docs()`
  --filter                     With test: Only run tests and corpus rows whose name contains the text; --filter=<text>, `filter: "x"`, `t.filter("x")`
  --capture                    With test: Show test output for failed, all, or none of the tests (default failed); --capture=all, `capture: all`, `t.capture("all")`
  --update-snapshots           With test: Replace expected snapshot output and bless every selected corpus row; --update-snapshots, `update_snapshots: true`, `t.update_snapshots()`
  --shuffle                    With test: Run tests in the order the seed picks; --shuffle=<n>, `shuffle: 7`, `t.shuffle(7)`
  --serial                     With test: Run tests one at a time instead of the parallel default; --serial, `serial: true`, `t.serial()`
  --measure                    With test: Measure `.measure` claims; --measure, `measure: true`, `t.measure()`
  --trace-tiers                With test: Report the tier each test ran at; --trace-tiers, `trace_tiers: true`, `t.trace_tiers()`
  --time-limit                 With test: Bound each test's wall time, such as 60s; --time-limit=60s, `time_limit: 60s`, `t.time_limit("60s")`
  --opt-in                     With test: Also run the corpus rows that are opt-in only; --opt-in, `opt_in: true`, `t.opt_in()`
  --shard                      With test: Run slice I of N of the selected tests and corpus rows, as I/N; --shard=3/8, `shard: 3/8`, `t.shard(3, 8)`
  --list                       With test: Print the selected tests after filter and shard, run nothing, exit 0; --list, `list: true`, `t.list()`
  --cases                      With test: Only run the tests and corpus rows the file names, one name or id per line; --cases=<text>, `cases: "x"`, `t.cases("x")`
  --jobs                       With test: Run at most this many corpus entries at once (default: from the cores); --jobs=<n>, `jobs: 4`, `t.jobs(4)`
  --memory                     With test: Bound the memory the running corpus entries claim together, such as 16G; --memory=16G, `memory: 16gib`, `t.memory("16G")`
  --allow-shrink               With test: Let `update_snapshots` bless fewer diagnostics for the listed ui rows, comma-separated; --allow-shrink=<text>, `allow_shrink: "x"`, `t.allow_shrink("x")`
  --diagnostic-coverage        With test: Check the ui suite's emitted and rendered codes against tests/diagnostics_coverage_allowlist.tsv instead of its rows; --diagnostic-coverage, `diagnostic_coverage: true`, `t.diagnostic_coverage()`
  --results                    With test: Write every selected test's verdict to the JSON file; --results=<text>, `results: "x"`, `t.results("x")`
  --compiler                   With test: Build and run the tests with the named jet; --compiler=<text>, `compiler: "x"`, `t.compiler("x")`
  --jetpack                    With test: Run the corpora's jetpack steps and engine verbs with the named jetpack; --jetpack=<text>, `jetpack: "x"`, `t.jetpack("x")`
  --where                      --where=<text>, `where: "x"`, `t.where("x")`
  --grade                      With test: Select the generated property-test grade: generated; --grade=<text>, `grade: "x"`, `t.grade("x")`
  --iterations                 With test: Generated-grade case budget (default 1000); --iterations=<n>, `iterations: 4`, `t.iterations(4)`
  --time                       --time=<n>, `time: 4`, `t.time(4)`
  --seed                       With test: Generated-grade base PRNG seed (default: fixed 0, reproducible); --seed=<n>, `seed: 7`, `t.seed(7)`
  --corpus                     --corpus=<text>, `corpus: "x"`, `t.corpus("x")`
  --browser-retries            --browser-retries=<n>, `browser_retries: 4`, `t.browser_retries(4)`
  --browser-reporter           --browser-reporter=<text>, `browser_reporter: "x"`, `t.browser_reporter("x")`
  --browser-ui                 --browser-ui, `browser_ui: true`, `t.browser_ui()`
  --browser-visual             --browser-visual, `browser_visual: true`, `t.browser_visual()`
  --browser-trace              --browser-trace, `browser_trace: true`, `t.browser_trace()`
  --update                     With import: Merge generated Jet into an existing target
  --coverage                   With test/inspect build: Show function or diagnostic coverage
  --ast                        With emit: Print the parsed syntax tree
  --ir                         With emit: Print the slot IR the native backend builds
  --fn                         With emit --ast/--ir: Print only the named function
  -u                           Short form of --update-snapshots
  --release                    With build/run/dev/jobs/test/inspect: Optimize for release
  --profile                    With build/run/dev/jobs/test/check: How hard to optimize: release, debug, or a named optimization bundle
  --optimize                   With build/run/dev/test/inspect: How hard to optimize: none, basic or full; with test: Run the tests at each listed optimize level: none, basic or full; --optimize=none,full, `optimize: [none, full]`, `t.optimize(["none", "full"])`
  --bounds                     With build/run/dev/test/inspect: What a failed bounds check does: fatal, report or off
  --debug-info                 With build/run/dev/test/inspect: Whether the image carries DWARF debug info: true, false or split
  --small                      With build/run/dev/test/inspect: Favor a smaller binary by keeping inlining to the O1 limits: true or false
  --inline                     With build/run/dev/test/inspect: Which calls the optimizer inlines: auto, always_marked or off
  --backtrace                  With build/run/dev/test/inspect: What a fault report shows of the stack: full, brief or off
  --dead-code                  With build/run/dev/test/inspect: Whether the image keeps the package's unreached functions: remove or keep
  --checked-alloc              With build/run/dev/test/inspect: Build with the checked memory allocator, which stops at a bad free or a write after free: true or false
  --write-generated            With build/run/dev/test/inspect: Whether fn build's generated sources are written to .jet/generated/: off or on
  --output-dir                 With build/run/dev/test/inspect: The directory jet build writes its executables to ("" is .jet/build)
  --libs                       With build/run/dev/test/inspect: More C libraries the native link resolves foreign symbols against
  --link-args                  With build/run/dev/test/inspect: More native link inputs: -L<dir>, -l<name> or a .a archive path
  --os                         With build/run/dev/test/inspect: The operating system the image runs on: linux, macos, windows, web or freestanding
  --min-os                     With build/run/dev/test/inspect: The oldest OS version the image runs on ("" is none)
  --action-timeout             With build/run/dev/test/inspect: How long one build step may run, such as 10min
  --set                        With build/run/dev/jobs/test/check: Set one declared package setting as key=value
  --threads                    With build/run/check/test/dev/inspect: Use at most N compiler threads (1 = one thread); without it jet picks a safe number of compiler threads
  --trace                      With build/run/check/test/emit: Stream the compiler's phases and progress to stderr, or to FILE with --trace=FILE
  --builder                    With jobs: Select a previously bound remote builder
  --a11y                       With lint: Check roles, labels, and other accessibility basics
  --complexity                 With lint: Report per-function cognitive complexity
  --max                        With lint --complexity: Fail when a function exceeds this score
  --scope                      With inspect: Choose a ledger or trust scope
  --core                       With inspect structure: Show the canonical core module export facts

  --record                     With test: Record a named replay as --record=<name>
