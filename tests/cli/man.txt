.TH JET 1 "" "jet VERSION" "Jet Manual"
.SH NAME
jet \- the Jet compiler and project tool
.SH SYNOPSIS
.B jet
.RI [ command ] " " [ args ...]
.SH DESCRIPTION
jet builds, checks, runs, and tests Jet programs, and manages Jet projects and their dependencies. Output is plain when piped and colored on a terminal.
.SH COMMANDS
.TP
.B run
build, then run a program (or a project)
.TP
.B check
look for problems, build nothing
.TP
.B test
compile and run top-level test blocks
.TP
.B build
compile to a native binary in ./build/
.TP
.B dev
watch a file and re-run it on every save
.TP
.B new
create a new project folder
.TP
.B fmt
rewrite a file to canonical style
.TP
.B fix
apply all auto-fixable diagnostics in place
.TP
.B explain
print the offline essay for a diagnostic code
.TP
.B doctor
diagnose the toolchain and offer fixes
.TP
.B env
enter the project dev shell
.TP
.B bind
generate a C binding cache from a header
.TP
.B add
add a dependency and fetch it
.TP
.B remove
remove a dependency
.TP
.B fetch
download and link all dependencies
.TP
.B update
refresh moving dependency selectors
.TP
.B store
inspect or verify the package store
.TP
.B gc
remove unreferenced store entries
.TP
.B publish
publish the current package to the registry
.TP
.B vendor
copy all dependencies into vendor/
.TP
.B audit
check dependencies against the advisory database
.TP
.B sbom
emit a software bill of materials from the lockfile
.TP
.B emit
emit generated output (--rust: print Rust source)
.TP
.B eval
evaluate a pure Jet program to stable JSON (--pure required)
.TP
.B bench
benchmark a Jet program with honest stats
.TP
.B completions
print shell completions (bash | zsh | fish)
.TP
.B man
print the jet man page (roff)
.TP
.B lsp
language server (stdio JSON-RPC)
.TP
.B version
print compiler version
.TP
.B upgrade
how to download a newer release
.TP
.B help
print the help text
.SH FLAGS
.TP
.B --json
emit machine-readable diagnostics
.TP
.B --color
color: auto | always | never
.TP
.B --version
print compiler version
.TP
.B --emit-rust
also print the generated Rust code
.TP
.B --check
with fmt: exit 1 if the file would change
.TP
.B --small
with build/run: smallest binary (S15)
.TP
.B --locked
with fetch: verify only, refuse network
.TP
.B --annotated
with new: include commented example deps
.TP
.B --force
with publish: bypass pre-publish gate (with warning)
.TP
.B --spdx
with sbom: emit SPDX tag-value format (default)
.TP
.B --cyclonedx
with sbom: emit CycloneDX JSON format
.TP
.B --advisory-db
with audit: path to advisory database file
.TP
.B --verbose
with build: print the bridge steps
.TP
.B --online
with doctor: allow network checks
.TP
.B --fix
with doctor: apply auto-fixable problems
.TP
.B --dry-run
with fix: show changes without writing
.TP
.B --try-anyway
with dev: interpret past unsupported features (no guarantees)
.TP
.B --pure
with eval: require the program to be pure (S60 / D-PURE2)
.TP
.B --freestanding
with build/run: no OS; rejects std-only APIs (E2-M15)
.TP
.B --target
with build: cross-compile for a rustc target triple (E2-M15)
.TP
.B --capabilities-json
with build: emit capability summary as JSON (D-TOOL5)
.TP
.B --update-snapshots
with test: update snapshot golden files (D-TOOL4)
.TP
.B --rust
with emit: print the generated Rust source (D-TOOL3)
.TP
.B -u
short form of --update-snapshots
.SH FILES
.TP
.B payload.jet
The project manifest.
