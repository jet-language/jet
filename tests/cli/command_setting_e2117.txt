Error [jet.FlagNotASetting]: `test.update_snapshots` in `package` line 4 would remember `--update-snapshots`, which you type each time you mean it.
 Why: A settings file applies a flag to every run, but `--update-snapshots` is typed each time: it deletes, overwrites or skips a safeguard.
 Fix: Remove `test.update_snapshots` from `package` line 4, and type `--update-snapshots` on the command line of the run that needs it.
