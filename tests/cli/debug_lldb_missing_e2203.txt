Error [jet.DebuggerUnavailable]: `jet debug` could not run the native debugger: LLDB is not on PATH.
 Why: `jet debug` steps through the real compiled program under LLDB, stopping at breakpoints and showing its frames and locals; without a working LLDB session there is nothing to step through.
 Fix: Install LLDB (the Jet dev shell provides it) and rerun `jet debug <file>`, or use `jet run <file>` to run the program without the debugger.
More: jet-lang.dev/e/E2203
