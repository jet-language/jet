.TH JET 1 "" "jet 1.0.0" "jet Manual"
.SH NAME
jet \- the Jet compiler and project tool
.SH SYNOPSIS
.B jet
.I command
[\fIargs\fR...]
.SH DESCRIPTION
jet is the command-line tool for the Jet language: it checks, builds, runs, tests, formats, and packages Jet programs.
.SH COMMANDS
.TP
\fBcheck\fR
look for problems, build nothing
.TP
\fBbuild\fR
compile to a native binary in ./build/
.TP
\fBrun\fR
build, then run (or run a project)
.TP
\fBtest\fR
compile and run top-level test blocks
.TP
\fBnew\fR
create a new project folder
.TP
\fBdev\fR
enter the project shell (jetpack enter)
.TP
\fBfmt\fR
rewrite a file to canonical style
.TP
\fBfix\fR
preview auto-fixable diagnostics (use --write to apply)
.TP
\fBbind\fR
generate a C binding cache from a header
.TP
\fBlsp\fR
language server (stdio JSON-RPC)
.TP
\fBexplain\fR
print the offline essay for a diagnostic code
.TP
\fBdoctor\fR
diagnose your environment (rustc, cache, PATH, FFI)
.TP
\fBcompletions\fR
print a shell completion script (bash|zsh|fish)
.TP
\fBman\fR
print the manual page (roff)
.TP
\fBversion\fR
print the compiler version
.TP
\fBhelp\fR
print the help text
.TP
\fBupgrade\fR
how to download a newer release
.TP
\fBadd\fR
add a dependency and fetch it
.TP
\fBremove\fR
remove a dependency
.TP
\fBfetch\fR
download and link all dependencies
.TP
\fBupdate\fR
refresh @latest / branch selectors
.TP
\fBstore\fR
inspect the content-addressed store
.TP
\fBgc\fR
remove unreferenced store entries
.TP
\fBinstall\fR
(redirected) use `jet store fetch` instead
.SH GLOBAL OPTIONS
.TP
\fB\-\-color\fR
when to colorize: auto|always|never
.TP
\fB\-\-json\fR
emit machine-readable JSON diagnostics
.TP
\fB\-\-version\fR
print the compiler version and exit
.SH SEE ALSO
Run \fBjet explain <code>\fR for an essay on any diagnostic code.
