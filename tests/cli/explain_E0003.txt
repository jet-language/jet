E0003

What this means:
  expected X, found Y, or a retired surface form such as prefix `$`

Why Jet enforces it:
  the parser knows the one current form for this declaration; compile-time and fact reads use prefix `@`, while infix `@` package refs stay unchanged

How to fix it:
  write the form named by the diagnostic, such as `@name`, `@if <condition> { … }`, or `T.@layout`; keep `target@provider` for package refs

Example:
  fn save(path: String) ? IOError {
      print(path)
  }

This explanation comes from jet's diagnostics reference.
