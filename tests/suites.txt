# Routine verification sets: every declared test target belongs to exactly one (#2025).
#
# A target nobody runs is a target whose failures are invisible. `golden`,
# `ban_bare_panic` and `jit_run` were each found red while sitting outside every
# set an agent routinely ran, because membership was REMEMBERED rather than
# enforced. This file makes it enforced: it is the one list of sets, and
# tests/suite_membership.rs::every_test_target_belongs_to_a_named_set walks
# `tests/*.rs` and `crates/*/tests/*.rs` and fails when the two disagree.
#
# Scope: integration test targets. Cargo builds one test binary per file, so the
# filesystem walk IS the target inventory. Package lib/bin unit tests ride with
# their package and are covered by `--workspace`; they cannot fall out of a set
# on their own, which is the failure mode this file exists to stop.
#
# Nothing here is decorative. `scripts/agent/time-suites.sh --set <name>` reads
# this file to decide what to run, and `--set all` is the union, so the sets are
# a partition of the inventory rather than a description of one.
#
# The pins live OUTSIDE this file, in tests/suite_membership.rs, so a hand-edit
# cannot green the check by deleting the row that fails:
#   TEST_TARGET_FLOOR       rows may only GROW
#   UNASSIGNED_CEILING = 0  a target in no section is a failure, never a count
#   HOST_GATED_HELD_OUT     exact, with the observed gate and the owing card
#
# Rows are repo-relative paths without `.rs`, sorted, one per line.
