# Cross-platform application: notes

Build a keyboard-first notes application with add, edit, search, save, and
reload. Exercise focus order, Unicode text, an interrupted save, a read-only
directory, and a corrupt file. Run the same scripted interaction on Linux,
macOS, Windows, and the supported web target. Beginner mode uses the normal
window and storage defaults. Expert mode selects storage and rendering
backends without changing the interaction contract.
