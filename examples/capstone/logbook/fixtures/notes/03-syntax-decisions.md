Every user-typeable keyword and sigil lives in src/syntax.rs with a decision ID. Ratified decisions leave the queue — open items only in the ballot docs.

Before using syntax not listed as Ratified or Provisional, add a row to the Open Decisions table and stop work on that feature until the owner decides.

Cross-references: [[jet-philosophy]] defines the priorities that guide decisions; [[owner-design]] describes the approval workflow.
