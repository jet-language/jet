# Surface research: broad comparison

Load this reference only when the owner asks for a broad comparison, a full
surface sweep, or a comparison across several peer languages or sources.

## Comparison scope

Name the Jet gap, peer languages, workloads, and source set before collecting.
Cover only that declaration. Compare contextual equivalents, not isolated
syntax: show the origin's behavior, audience, defaults, error text, APIs,
tooling, safety, and expert control when those dimensions bear on the question.

Use the full micro sweep when the request is broad: syntax, ergonomics, surface
forms, APIs and types and methods, defaults, naming, error text, UX/DX, tooling
and CLI shape, and ceremony versus control. Record an empty category as a
result. Use the relevant standing-lens questions and five agent-optimality
quantities; do not run unrelated probes.

For each idea, record:

- exact source URL or repository, version or commit, publication date, and
  section, file:line, timestamp, issue, or decision locator;
- the observed mechanism and failure mode;
- **Ceiling**: what the origin achieves and what limits it;
- **Jet's version**: one mechanism, safe default, expert opt-in, and a
  machine-checkable fact where the origin leaves a convention;
- what the peer must change to match Jet, including when it can copy the idea
  without breaking its model;
- Jet state and uncertainty.

Prefer primary sources. Separate source evidence from Jet inference. This is
research, not ratification.

## Stop

Stop when every named peer and surface category has evidence, a Jet use or
rejection, a failure to avoid, and an uncertainty record. A source gap is a
reported limit, not permission to expand the source set. Write one report under
`docs/research/` and do not create Tower work, ballots, or implementation edits.
