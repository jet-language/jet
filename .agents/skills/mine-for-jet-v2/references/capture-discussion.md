# Discussion: bounded thread, exact corrections

Read the declared whole thread or explicitly authorized sample. Record URL,
post IDs, dates, root/reply boundaries, edited/corrected claims, substantive
opposition and linked primary sources. Segment the thread by post range (≤ 1,500
words each); every segment gets a ledger and every lane; incomplete API threads are gaps.

Keep participants anonymous unless credibility depends on maintainer identity.
Reactions/votes discover leads, not technical consensus. Verify technical
corrections independently; mirrors and repeated upstream claims are not
independent corroboration. Use text first and the explicit cache capture root.
