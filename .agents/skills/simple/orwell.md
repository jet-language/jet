# Orwell's rules

Apply these rules to new natural-language prose when `simple` is active:

1. No stale figures of speech. Do not use a metaphor, simile, or printed phrase that hides the fact.
2. Prefer a short word when it carries the same meaning.
3. Cut a needless word. Keep required grammar words.
4. Prefer active voice when the agent is known.
5. Prefer an everyday word over decorative jargon.
6. Do not sound barbarous. Break a style rule before writing false or unclear text.

Source: George Orwell, “Politics and the English Language” (1946).

## With STE and Jet

| Tension | Resolution |
|---|---|
| Cut words vs keep articles | Cut filler. Keep required grammar. |
| Everyday words vs Jet terms | Keep exact Jet, API, code, path, ID, and diagnostic terms. Cut only decorative jargon. |
| Active voice vs unknown agent | Prefer active voice. Unknown agents may stay passive in a description. |
| Style vs truth | Clarity, meaning, safety, and exact wording win. |
| Code, identifiers, and errors | Never rewrite them into synonyms. |

## Quick rejects

| Reject | Prefer |
|---|---|
| “at the end of the day”, “move the needle”, “low-hanging fruit” | State the fact. |
| “utilize”, “facilitate”, “leverage” | `use`, `help`. |
| “in order to”, “due to the fact that” | `to`, `because`. |
| “it should be noted that” | Delete it; state the fact. |
| “a number of” | `some` or the real count. |
| “going forward”, “robust solution” | Say what changes. |
