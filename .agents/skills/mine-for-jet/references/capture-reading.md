# Capture an article, paper, or docs page

Fetch the canonical page or PDF with `read` on the URL first. Use browser tools
only when `read` cannot deliver the source.

Record the canonical URL, publication date, updates, and errata. For a paper,
capture the linked artifact or benchmark repository when available; it outranks
the prose for measured behavior.

Capture discussion only when the owner requests audience evidence or the named
question depends on reception. Then sample the largest one or two relevant
threads and record which threads were not read. Do not infer the argument from
the abstract, title, or search result.
