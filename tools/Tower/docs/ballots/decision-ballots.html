TOWER

Jet — Decision ballot

Mission control for building Jet. Decisions are full cards you tick and sign & file — rendered straight from docs/spec/decision-ballots.md, one source of truth.

Start it from the repo root (one command):

nix develop -c node tools/Tower/Tower.mjs serve --open

That serves the dashboard at http://127.0.0.1:4173 and opens your browser. Tick an option, hit Sign & file — choices are written (and merged) into docs/spec/ballot-results.md; then tell Claude "go" to ratify & implement. ↻ improve examples on any card queues a Claude review of that card's examples.
